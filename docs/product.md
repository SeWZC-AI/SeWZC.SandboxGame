# SeWZC.WorldBox 产品约定

本页只记录当前玩家行为与产品边界。实现入口见 [架构](architecture.md)，取舍来源见 [决策记录](decisions/README.md)，实际验收覆盖见 [构建与验证](verification.md)。下面的行为要求不代表所有设备与规模均已验证。

## 定位与原则

项目介绍保留“AI 写的项目，没什么用”。README 保持最简，只提供简介、浏览器与文档入口，不增加贡献者或问题反馈入口。

玩家循环：创造地形与居民 → 观察个人及文明演化 → 追查行动与事件依据 → 编辑或灾害干预 → 继续模拟。WorldBox 提供沙盒形式参考，孢子、文明与帝国时代提供演化和战争方向参考，不代表复刻其全部机制。

- 居民选择由需求、性格、职业、环境、经历和已知信息驱动，理由反映实际机制。减少无目的随机切换，允许有种子的自然随机性。
- 世界事实、居民相信的事、机构收到的报告分别保存。距离、路径、现场劳动、真实运输和信息时效具有实际作用，玩家的全局编辑明确属于干预。
- 种族、文化与国家独立，支持多种族国家、迁居和文化接触；改国家文化不瞬间改写居民认同。
- 科技与魔法允许并存，各自有独立研究和动力基础。新增机制须有可观察结果、干预入口和可靠保存，不能只增加节点或说明文字。
- 查看、筛选、导航、跟随及动画不修改世界或消耗模拟随机数。编辑个人历史只影响当前认知和未来，不回算既有战争、死亡或交易。
- Avalonia 界面共用，浏览器可在 GitHub Pages 仓库子路径纯静态运行，无游戏服务器、在线模型或 API 密钥依赖。
- alpha 不提供旧格式迁移，当前格式仍须完整校验、失败保护及确定续演。容量、费用、比例、布局尺寸等工程参数可依据需求和证据调整。

文明兴衰、冲突与人物故事是主要乐趣。正常速度约 1–3 分钟有值得关注的变化、10–20 分钟看到一段发展是体验调优目标，不是强制事件定时器，也不保证每个聚落完成所有研究。

## 地理、生存与生态

海拔仅参与地图生成，不影响之后的移动、劳动、建造、通信或视觉高度。降水、肥力和淡水距离独立影响地形；河道沿排水路径通海，有可步行小溪及需要桥舟的大河，小湖独立。默认四部落具有完整宜居范围并预占初始土地；后续投放和拓荒不重复赠送默认部落范围。

四种族具有不同寿命、需求、宜居地及移动／劳动效率；可通行与宜居分开判断。矮人可穿行天然山地，其他普通步行者需要山路。每族特殊建筑由当地成年居民解锁并实际运作，混合聚落可以使用多族设施。

粮水先在仓库实际领取并随身携带，到达家园后交付余量。居民到本格或淡水岸边取水；河湖无限淡水，实际取水、背包和运输仍有限。陆地共享有限日供水，干旱影响额度，未用水不累积。水井按天然供水提供有阈值的新增能力，仍须到场抽取并运输；具体公式见 [供水规则](../src/SeWZC.WorldBox.Core/WorldEngine.Provisioning.cs)。界面统一用一个“供水量”字段，不拆分来源。

动物以地格内连续群落共存，体型、食性与栖息地影响容量和捕食。食草物种共享植物供给，捕食者共享兼容猎物；缺食先导致捕食者饥饿死亡，严重过量仍可连续耗尽猎物，没有灭绝开关或自然猎物保底。固定适宜环境的满容量食物网保持补充与捕食平衡；破坏、缺水或捕猎可以改变结果。动物分区、植物错峰复评，观察不触发生态更新。

居民狩猎及岸边／舟船捕鱼扣实际种群，低密度时减速并选择更好来源；一次最多取当前种群一成，自主居民不持续采集低于当地容量一半的猎场。自然植物采集同样保留恢复存量，采食与伐木分别扣对应植物。乔木、灌木、草本、芦苇和作物显示具体生物量及产物，不虚构逐株计数；自然资源恢复使用生成容量，玩家赐予的超额资源不被自然恢复削减。

牧场和水产养殖厂实地取种、消耗真实食物、水或草料，需到场照料与收获，长时间缺少照料会减群；不赠送牲畜或后台免费产物。狩猎营和林场竣工保留当地森林资源，其他清理行为按实际建造规则执行。

## 居民、信息与制度

居民目标有合理持续性，生存、危险、资源耗尽、失效岗位或阻路仍可打断。劳动、进食、交付和施法满足真实位置与到达条件。探索从眼前可通行土地推进，不隔空发现地址或材料；死亡记录最后致命损伤的具体原因。

当面交流经投递队列，信使、商旅和代表实际移动。消息保留观察／获知时间、原始来源、当时职业和可信度；转述不能刷新旧观察或同一步无限接力。信号研究只解锁设施，远程通信仍需运作、覆盖及连接。

自治政策按机构收到的报告、制度权限和议题相关性加权；递送者不替换原作者职业，同一报告不重复计票。玩家政策覆盖立即生效并持续到恢复自治，须标明干预。文化接触可以改变认同，不将种族变为永久阵营。

商贸依据本人获知的粮情、地址和敌对信息选择目标；装货时保留本地储备，到站按实际支付能力交换，零成交不算成功贸易。未成交货物与所得须实地带回，途中未收到的宣战不隔空取消任务。饥荒迁居抵达并获接纳后才改变归属，地方分裂依赖实际送达的持续困苦报告。

## 城镇、建设与运输

每个聚落有唯一实际城镇中心。人口只提高最大占地范围，建造者到边界格驻留后登记；领地按四邻接连至中心，水格不能串联陆地。迁城、删城、转让或陆水转换修复连通性，断开的占地释放，非法飞地存档拒绝。玩家领土笔刷同样从既有城镇边界连通扩展。

普通建筑含直接赐予须在本城镇登记的连通领地建造；船坞、码头等水上设施贴近本城镇占领陆岸。公共道路、桥梁和山路不要求领地，也不因建造改变归属。普通设施失去占地后暂停工作。

25 格本城镇独占陆地启用城镇加成；升级面积按当前最大半径的一半向上取整所对应的菱形面积计算，具体见 [城镇规则](../src/SeWZC.WorldBox.Core/WorldEngine.Towns.cs)。村升镇、镇升城保留 60／160 人门槛，还需材料及到中心施工。已取得等级保留，面积不足暂停加成或扩充；城镇中心建筑升级独立，晋升不新增战斗加成。

创始村有公共补给；后续建村由实际勘察报告选址，支付费用并携物资步行到场，保持中心间距和可扩张陆地。自主建造先确定用途，筛选有资源、合法且施工可达的位置，再支付材料，并保留选择理由。住房、拓荒和生产不能耗尽下一发展项目预留的物资；缺料可选项目不阻塞可负担项目。

玩家建设默认直接赐予，可改为付费居民施工；赐予不授予研究、工作人员或运营材料。建筑支持付费或赐予升级，施工中的生产与旧通道语义按统一规则处理。桥梁仅左右／上下，步行边两端须匹配方向，离岸按轴向自然岸计量，旧桥到改向或升级完工才切换。自动桥梁服务已知任务，先检查可见陆路、对岸和预算，不为无目的探索或采集铺桥。

船坞制造实际舟船，独立码头提供交通服务，航空工场制造飞机；借用载具和往返燃料从仓库支付，交付和归还必须实地抵达。渔民借舟船航向可达鱼群，现场劳动并返乡交付。铁路升级本国已有陆地道路、实际支付材料，连通路段影响移动；当前没有独立船队、跑道或完整交通调度。

## 研究、生产与魔法

研究名称、前置、成本、解锁统一以 [Advancement 目录](../src/SeWZC.WorldBox.Core/Advancement.Catalog.cs) 为准，路线与解锁查询见 [ResearchRules](../src/SeWZC.WorldBox.Core/ResearchRules.cs)，配方以 [ProductionRules](../src/SeWZC.WorldBox.Core/ProductionRules.cs) 为准。研究需支付当地材料并由学者在完工学舍实际推进；收到远方成果不自动补齐前置。古代 1–5 级编辑参数与时代知识分开，不按新增研究无限提高旧倍率。

科技包括工业、能源、制造、信号、航空及铁路；魔法包括训练、晶体、符文及以太工艺。工人返仓领料，到设施逐批加工，产物进背包并亲自返乡入库；生产设施需完工、健康至少 50／100、启用、领地及相关知识。桥梁、山路已铺设通道按实际地块判断通行。魔法生产还检查个人天赋、训练和魔力。库存达到补货目标后停止新领料，新设施可在真实条件满足时先完成一批投产。

国家可选择依文化自动发展、科技、法术传承、魔法工艺或兼修，独立国家继承偏好。法术传承不强制晶体产业，科技不依赖魔法动力。基本生存和有用设施按缺口优先，军备、医疗、贸易、铁路等研究与设施按当地需要选择，无合适人才时不盲目研究魔法。

科技帝国与魔法帝国是只读文明结果：同一城镇掌握完整路线，必要产业链可运作并有真实首批生产。医疗、军事和折跃按需建设，不为认证强制空建；没有帝国研究节点或额外产量奖励。停用、失地、受损或知识不完整会使当前判定退回发展中。完整研究实验须区分付费议程与纯自主决策，不能将和平时跳过军备判为发展停滞。

| 研究玩法 | 实际效果 |
| --- | --- |
| 公共服务 | 水务运输真实用水，医师消耗药品治疗现场患者，消防员携水扑救并携石修复 |
| 教育与勘测 | 图书馆教当地已有知识，勘测形成带位置、时间和遮挡条件的观察；异地知识仍需递送 |
| 工程与装备 | 工具提高实际施工，弹药射击须本人收到交战依据并满足距离／视线，护甲受击磨损 |
| 元素与结界 | 冻结、闪电、降雨、防护与战法消耗个人魔力及实际物资，作用于局部目标 |
| 自然与空间 | 炼金制药、育林恢复真实资源；折跃扣本人魔力和随身魔晶，携背包移动，当前由明确操作触发，不参与自主门户寻路 |

魔法是受天赋、训练、环境、研究、资源和魔力约束的中魔体系，有治疗、生产、保护和战斗效果。关闭“新的魔法发展”阻止新发起的相关研究、设施与训练；保留既有能力、已开始项目、知识传播及符合条件的生产。彻底删除某体系尚未提供。

## 战争、灾害与故事

个人资源争夺在真实现场由争执发展为对峙、暴力及群体冲突，离开或供给改善可降温；国家依据收到的信息积累敌意和持续争端才自主宣战，玩家外交仍可直接宣战。双方外交态度分别保存，界面均值不替代行动方依据。

每国的有限军队进攻已获知的指定聚落或防御家园；军令须实际送达并按时间和编号去重，换帅或分批递送不重演旧令。目标完成、失效、战损、补给、士气或受阻终止任务，不自动改打邻近目标。更新命令不清零累计作战疲惫与损耗。

现场见证者形成战报，首都收到后才据此停战与恢复；战果现场状态与机构已知结果分别展示。返乡归还实际补给，恢复期限制自主进攻而保留家园防御。群体冲突尚无独立内战军队，多战线与全面征服未实现。

火灾从少量火点逐步传播，依地形及建筑可燃性燃烧；携水居民到安全边缘劳动扑救，共享日额度防止堆人瞬间灭火。疫病从少数病例按实际接触传播，康复有暂时免疫。干旱影响生产和陆地供水。陨石是明确玩家干预，动画呈现已提交结果，不延迟伤害。

编年史、人物故事及前后因链接来自实际项目、消息和经历，不凭文字相似编造因果；日志及个人档案有容量边界，缺失前因明确说明。非重大同类事件可聚合呈现，原始记录保持独立。多对象关注只影响呈现，切换世界清空。施工／研究只在足够且稳定的实际样本下估计剩余模拟日，停工或变速率时说明失效。

## 观察、交互与编辑

- 内置字段用换行、标签或间距区分，不用点分隔；日期完整，默认姓名用空格，自定义文本按原文展示和搜索。说明只出现一次，受阻写具体原因，正常空值与次要信息折叠。
- 工具、暂停与速度入口稳定，刷新不破坏输入、选择、折叠和滚动。鼠标与触屏共享格式；地图缩放只影响地图，不缩放页面或顶部控件。
- 选择只显示名称及当前值／上限，详情主动打开；人物、建筑、地格显示真正相关状态、加成、来源与阻碍。建筑损伤及实际停工阈值默认可见，满级不提供无效升级。
- 聚落列表及“概况、建设、研究、通信”固定页签保持同一对象。相关对象可跳转，返回恢复选择、跟随、折叠、滚动与研究视野；关闭或地图操作结束浏览会话。
- 研究树连接每条真实依赖，分别显示科技、魔法与共同基础；分支筛选保留全部前置，周期刷新保留选择与视野。节点图不改变知识来迁就布局。
- 近景区分种族、职业、任务、建筑和物种；高建筑与居民／舟船按显示位置交错遮挡，屋顶命中真实建筑。流水、运动、灾害及法术共享可暂停呈现时钟，载入清空短暂旧效果。
- 居民及国家通过结构化表单编辑，数字有范围、引用有名称、位置可地图取点；目标、记忆和经历说明实际影响，不把自由文字当指令。仅改无关属性保留原目标，亡者档案编辑不复生、不领取现存物资。
- 国家改名、旗色或外交不移动或舍入未修改库存；领土转移维护聚落、居民和首都关系。失效对象入口禁用，换世界清除旧预览和排队请求。
- 窗口／取点只临时停表，取消恢复原偏好；有效编辑创建整轮恢复点并暂停。准备快照时可取消，旧请求不得修改新世界或关闭新窗口；一轮撤销不等于多级历史重演。

常用操作入口见 [操作指南](gameplay.md#操作)。后台、自动保存、当前格式及大小边界见 [存档说明](architecture.md#编辑与存档)。

## 验收与未实现范围

行为变化须验证对应因果：远方事实未送达不改变本方认知，转述保留来源且不重复计票；施工、采收、运输、服务和法术核对真实位置与物资；编辑不回算历史，非法输入不改世界；途中保存恢复确定续演；观察与真实交互不隐式修改世界；裁剪产物能在仓库子路径加载并保存。按 [开发约定](development.md#按改动选择验证) 选择相关场景，不能用编译或节点数量代替行为验收。

局部寻路、贸易、政治、生态和战争是简化模型，有有界记忆与日志，不保证最优路径、无限人生史或每个世界达到发展终点。真实 Android／iOS、Firefox／Safari 和大人口长期表现以 [验证记录](verification.md#验证边界) 为准。

家族继承、宗教与完整文化传统、复杂海战和现代军种、全面征服、电网、星际探索、多人、云存档、在线语言模型与自由文本指令理解尚未实现。后续优先完善现有生产、运输、政治、战争的平衡及解释，并测量规模和真机，再扩展科技与奇幻内容；未来方向不成为当前交付承诺。
