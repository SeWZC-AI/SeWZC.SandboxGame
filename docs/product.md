# SeWZC.WorldBox 产品约定

本文记录产品要解决的问题、已确认的行为约定及其原因，供后续开发者和 AI 接续工作。它是持续维护的当前产品基线；[第二轮范围](iteration-2-spec.md)保留当时的问答结论，[架构说明](architecture.md)解释实现边界，[验证记录](verification.md)记录具体构建的检查结果。本文列出的验收要求不等于每个浏览器、设备或规模均已验证。

文档分工见[文档索引](README.md)。修改产品行为时，按[开发约定](development.md)更新相关约定、原因及验收场景；重要取舍记入[决策记录](decisions/README.md)。现有代码中的数值、集合容量、职业比例、按钮槽数和规则权重属于可调整实现，不能仅因已经存在便当作用户永久要求。

## 产品定位与玩家循环

`SeWZC.WorldBox` 是 `SeWZC.SandboxGame` 的首个 2D 上帝沙盒，采用 C# / Avalonia，支持桌面与 GitHub Pages 浏览器运行。WorldBox 提供沙盒形式参考；孢子、文明和帝国时代提供文明演化与战争的方向参考，不代表复刻其全部机制。

玩家的基本循环是：创造地形与居民 → 观察个体生活及社会演化 → 查看行动依据与世界事件 → 编辑角色、国家或环境进行干预 → 继续模拟并比较结果。玩家既能旁观，也能直接改写世界；模拟中的居民和机构则受到当地资源、位置、能力及已知信息的限制。

当前是从古代起步、可推进至未来制造与高阶魔法生产的文明原型。科技和魔法可共存，但保持各自的研究与动力来源，不以过度融合代替两条路线的发展。单纯增加按钮、文本或数值而没有可观察结果，不算完成一个新机制。

## 产品原则与当前行为约定

以下原则来自已确认的产品方向；标注为“当前实现”的细节描述现有行为，不代表用户曾逐项指定，也不妨碍后续在保留设计原因的前提下调整。

### 1. 行为应有依据，认知与世界事实分开

居民根据需求、性格、职业、当地环境、资源、经历与已知消息选择目标，并保留真正影响本次选择的理由。国家与地区的文化、政策等社会条件也应通过实际机制影响个人，而不是只在面板上展示。

减少无目的的随机换目标和散点移动，不等于禁止所有随机性。地图、个体差异和自然事件仍可使用可复现的随机过程；重要选择应能回答“为什么此人此刻这样做”，同一目标应具有合理的持续性。

世界中客观发生的事、居民相信的事、机构收到的报告是不同状态。玩家可以查看全局事实，居民不能因为引擎保存了某个远方值就立即知道它。错误或过时认知可以造成合理的错误决定，界面应让玩家看懂其依据。

原因：纯随机行为难以形成连续故事，全知决策会抹去探索、运输、传播和社会制度的意义。当前认知来自有边界的规则，不调用在线语言模型；解释文本应反映实际规则，不伪造未发生的推理。

### 2. 通信必须有地点、路径和时间

早期通信通过当面交流，以及实际移动的信使、商旅和代表完成。消息保留观察时间、获知时间、来源及可信度；转述不能把旧消息变成刚刚亲眼观察的事实，也不能在同一步无限传遍世界。

远程通信需要可运作的设施、覆盖和连接。研究某项通信科技，不会让所有居民自动获得全球即时知识。道路、地形、人员抵达、设施故障及连接中断应影响运输或消息到达。

原因：信息传播本身是文明发展的机制，应让距离、基础设施与信息时效产生真实差异。当前先处理过时信息与来源差异，尚未加入随机谣言、蓄意欺骗或完整语言系统。

### 3. 公民通过制度影响社会决策

公民对聚落和国家的影响，应根据制度、身份及议题相关性体现不同权重。当地议事与代表递送形成可观察的过程，机构根据实际收到的材料决策，不能直接读取全国居民的内心。

原始信息来源与递送者应区分：农民观察到的粮食问题，经信使送达后，不能变成“信使的职业意见”。重复转述同一报告不应重复计票，陈旧或可信度不足的材料应影响判断。

原因：制度差异需要改变因果关系，职业与资源处境需要能够形成诉求；只修改国家面板标签不能体现文明差异。当前制度和议题权重是简化模型，数值可以随平衡与验证调整，不声称复现真实政治。

当前实现中，玩家直接指定国家政策属于上帝编辑，可以立即作用于该国并持续覆盖自治；恢复自治后才重新由模拟决策。该操作须标明玩家干预，不能伪装成角色通过远程通信形成的共识。

### 4. 种族、文化、国家独立

种族描述生理与固有能力差异；文化描述认同与价值；国家组织领土、制度、政策和外交。三者分别建模，允许多种族国家，也允许同一种族属于不同文化和国家。

文化可以通过接触与社会过程变化，不能把种族当作永久阵营。修改国家文化不应瞬间改写所有居民的认同，迁居和归属调整也须保持这些概念的区别。

原因：将三者绑定会使社会演化退化成固定阵营对抗，限制迁徙、交流、分裂和融合。当前文化只有有限价值维度与接触传播，完整传统、宗教及更丰富的思潮仍待扩展。

### 5. 编辑角色改变现在与未来，不回算过去

玩家可查看和编辑角色身份、身体状态、归属、职业、随身物品、魔法属性、目标、性格、思想、记忆及个人经历。常见操作使用结构化表单；数字使用带范围的数值控件，枚举和对象引用使用有名称的选择器，位置可从地图取点；普通入口不暴露 JSON。目标理由、记忆说明和经历说明由结构化选择生成；不提供无行为含义的自由文本编辑。经历类型与影响强度解释实际作用并提供快捷强度选项。

属性修改直接影响当前状态；结构化记忆、目标和经历影响认知及未来行为。改写某人的历史，不会重新执行过去的战争、资源交易或死亡；修改亡者档案不会使其复生。已经传给他人的消息也不会被追溯改写。

亡者的历史位置与军队归属允许保留已消失对象的引用；仅编辑档案不启动运输任务、不领取现存聚落物资。身份文字与存档采用一致校验，冲突的信息快照须在提交前拒绝；允许的年龄上限在后续模拟中仍保持可保存、可恢复。

目标编辑器按任务区分建筑与居民引用，并保留记录中已消失的目标。仅修改人格或需求时保留原目标与引用，不重新指定任务；正在农田、学舍或奥术设施工作的居民同样可以编辑人格。

原因：允许玩家塑造人物故事，同时保持世界因果与存档可理解。姓名等身份文字不作为自动执行的世界指令；经历的心理影响来自可解释的结构化规则。

所有编辑须保持实体关系有效，失败时不应留下半次修改。查看、筛选、定位和镜头跟随均只读世界；它们不能隐式推进模拟或改变随机序列。编辑撤销的当前边界见下文，不能与历史重演混淆。

### 6. 魔法采用有约束的中魔基线

幻想方向采用偏中文小说中西式奇幻的中魔氛围：魔法既不是人人精通的日常万能工具，也不是几乎不会出现的奇迹。种族影响天赋与擅长方向，实际成长及使用受到训练、当地环境、研究、设施、资源和魔力约束。

魔法需要影响已有生活机制，例如治疗、生产、保护与战斗，并有真实目标、范围和消耗。不能只增加不影响世界的特效或“魔法等级”。

“允许新的魔法发展”控制发展路径，关闭后不清除已有能力与成果，已有施法者仍可施法。

当前实现中，关闭开关会阻止新发起的奥术研究、新秘法设施及训练；已开始的研究和建设仍可继续，已有知识仍可传播。这些项目边界来自代码，不是用户逐项确认的永久要求；以后调整时，应同步更新开关说明与验收。

原因：普通规则开关用于控制后续发展，不应暗中删除玩家世界。彻底移除某体系属于独立的世界转换功能，当前尚未提供。

### 7. 交互稳定，观察能够支持理解

用户明确要求不用点作为内容分隔。所有内置界面文案，包括顶部、状态栏、工具提示、故事、战报、库存与配方，按字段换行、标注标签或增加间距。日期作为完整字段显示；默认人物姓名用空格连接名与姓，避免间隔点。

工具分类、可用动作和状态文本变化时，核心工具入口及暂停、速度控件应保持稳定位置。不可用动作应表达原因；响应式布局可以因屏幕尺寸调整，但不能因每次模拟刷新持续跳动。输入中的内容、选择和滚动位置不应被周期刷新破坏。

地图缩放只改变地图镜头：缩放按钮、滚轮与双指捏合均不得放大整个应用、移动页面视口或改变顶部栏、工具及时间控件的大小与位置。浏览器入口限制原生页面捏合缩放，并拦截双指触摸与 WebKit 手势的默认行为；事件仍交给共享界面处理地图导航和控件输入。

地图支持选择地格、建筑与居民；选择只显示摘要，点击“查看”打开详情。手机详情默认不超过地图高度的一半，可手动展开；详情与表单减少留白。支持定位和跟随居民；档案区分客观状态、当前目标、行动理由、消息来源及个人历史。日志按重要程度组织，显示清晰的时间、国家与事件类型，并允许筛选和定位。普通贸易、通信等高频消息不应淹没建国、战争或灾害等重要变化。

居民按真实目标移动，显示层在逻辑位置间平滑呈现。暂停时冻结，载入和编辑传送时正确重置；高帧率只改善呈现，不改变模拟结果。

查看中的聚落消亡后，详情切换到仍存在的聚落或空状态；切换世界时取消旧地图的放置预览。国家编辑只重设明确修改的资源项，改名、换旗或修改外交不移动各聚落已有库存，也不舍入其数值。

原因：稳定的操作位置减少误触，可解释的观察工具让玩家理解演化过程。连续运动用于呈现真实过程，不能用视觉插值掩盖瞬移式生产、运输或通信。

### 8. 地理与资源必须进入机制

地形差异应体现在肥力、资源、通行、魔力或灾害条件上。劳动、进食、货物交付和施法需要满足实际位置条件；居民随身库存、聚落库存与正在运输的货物应相互一致。

文明自主建设与研究需要投入及实际工作，玩家地图建筑工具默认直接赐予完工建筑，也可切换为消耗当地材料、等待工人施工；赐予不自动解锁研究或提供运作人员。道路应影响通行。当前道路笔刷是玩家直接施工工具，不代表已经实现工人铺设每一段道路；创建世界和投放居民所需的初始条件也应与后续自主生产区分。

原因：地理是聚落选择、分工、贸易与冲突的基础。若库存隔空同步或劳动无需抵达，地形与运输就只剩视觉差异。

### 9. Pages 静态交付与 alpha 边界

浏览器版必须能以纯静态文件部署到 GitHub Pages 的仓库子路径，不依赖游戏服务器、在线模型、API 密钥或专用响应头。桌面与浏览器共享模拟规则，平台差异主要体现在启动、输入和存储。

浏览器存档是当前站点的本地数据，提供导入导出作为可携带备份；当前没有账号与云存档。后台页面暂停，不根据离线时间补算发展。

主分支及 Pages 发布分支统一为 `main`，产品仍处于 alpha 阶段；主分支名称不表示稳定发布。应用版本以 [Directory.Build.props](../Directory.Build.props) 为准。

用户明确：**alpha 不考虑兼容性**。允许修改内部接口、布局和存档格式，不为旧格式保留迁移逻辑；旧版及未知格式应明确拒绝并提供新建世界路径。这个约定不豁免当前格式的校验、可靠恢复或失败保护。

当前存档格式及模拟版本为 14，保存饮水、占地、升级、扑救额度、康复免疫、城镇扩充、有界寻路历史，以及工具、药品、弹药、个人防护、战斗冷却和新设施服务记录等状态。旧 alpha 格式明确拒绝载入，不通过猜测补全。

原因：早期产品需要自由调整数据与交互，兼容层会增加尚未稳定机制的维护成本。相同程序版本中，保存后恢复应延续同一世界与随机过程；不承诺跨版本模拟结果相同。

以下是当前能力清单，不把“基础”解释为完整文明模拟。操作方式见 [README](../README.md#操作)，具体数值与实现见代码和[架构说明](architecture.md)。

| --- | --- |
| 创世与环境 | 种子世界、地形笔刷，深水、水、沙地、草地、森林、山地、雪地、丘陵、湿地、沙漠、河流、苔原、小湖、旱原；土壤和供水独立影响生活与生态 |
| 居民 | 人类、精灵、矮人、兽人；需求、性格、职业、目标、记忆和经历；地图选择、档案、定位、跟随与编辑 |

| 文化与治理 | 独立文化认同及接触传播；议事会、君主制、行会议会；粮食、防务、求知、医疗等政策与玩家覆盖／自治切换 |

| 魔法 | 天赋、训练及魔力；治疗、丰饶、护盾与战斗法术；自主使用和玩家指定施法目标 |
| 国家与冲突 | 国家名称、旗色、库存、发展水平、外交和领土编辑；聚落独立、归属转移、领土扩张及简化陆战 |
| 灾害与观察 | 火灾、干旱、疫病与玩家释放陨石；自然灾害规则与玩家干预；分级、筛选和定位世界事件 |
| 时间与保存 | 暂停与倍率、连续运动、当前会话的一轮编辑撤销、自动保存、导入导出和当前格式恢复 |

保存捕获期间世界时间短暂停留，仍可拖动地图及观察；编辑会取消尚未完成的捕获，保留上一份有效存档。捕获完成后继续模拟，不追赶停留时间。

国家会根据首都实际收到的聚落接触与贸易消息、本地粮情和政策调整关系，自主提出结盟、开战或停战；结盟提议需要实际送达和回应。军令仍需要传到前线。持续收到困苦诉求的非首都聚落可分裂，饥饿居民依据获知的粮情步行迁居，抵达并确认接纳后才改变归属。玩家也可直接编辑外交。国家的古代发展水平是编辑参数，不等于完整时代科技树，也不自动完成各聚落研究。

当前外交评估分别保存双方依据本地资料累计的态度；宣战与结盟提议的态度门槛只读取行动方自身的值，界面的关系分数展示双方均值。各对国家按稳定编号处理，目标位置来自收到的联系报告；远方尚未传出的粮情、政策或迁都不直接改变本方态度与军令排序。共享的战争／结盟状态与冷却仍记录客观关系，每次评估一对国家最多执行一次外交动作；现有战争可由任一方依据当地情况提出停战，发起方清除自身敌意，对方收到停战声明后才清除其敌意。

商贸先依据商人实际获知的粮情与地址选择目标，到粮仓装货时再检查可用余粮。当前装货保留每位本地居民一份粮食且至少 12 份，作为工程默认储备线；多个商人按实际剩余库存装货，旧余粮报告不能支取当地储备。到站按实际可支付的木材、粮仓和随身容量交换（当前一份粮食换 0.4 份木材），不将付不起的差额当成赠送。保留返程口粮，未成交的货物和收到的木材均须实地带回；零成交不生成成功贸易事件或改善关系的交易证据，人物目标与决策记录说明返乡原因。

商人不主动前往自己已知的敌对国家交易；途中实际收到敌对军令时停止交易并带货返乡，到站后也核对眼前聚落的归属。远方尚未送达的宣战不会隔空取消商旅任务；消息递送与贸易成交仍是不同事项。上述约束完善现有粮木交换，不表示已实现新的援助、定价或多资源市场系统。

前线行动由指挥官实际收到的军令驱动，掉队士兵的知识须经通信送达。军队持久保存已采纳军令的观察时间与编号，只接受顺序更新的军令；换帅不倒退，同日军令分批到达时仍按编号判定先后。

较新的有效宣战令实际送达后，可替代先前停战令并更新本次作战关联；因目标完成、损耗或补给等实际原因结束的任务仍保持撤退。新命令不重置累计作战时长和初始兵员，不能借此清除疲惫或伤亡。

研究中的学舍毁坏后，自主建设可在材料与劳动力允许时重建并续研；建筑预检与实际支付使用同一材料精度规则。多个本国聚落的保护范围重叠时采用实际覆盖中的最强保护，不按列表先后遗漏护盾，也不重复叠加。

自主发展中，住房扩张会为下一项当地建设或研究预留木材、石材，避免住房反复耗尽材料而让学舍和后续发展始终无法启动。缺少材料的可选项目可以暂缓，聚落继续选择已满足前置条件且能够支付的项目。设施工作目标对应具体建筑；工坊只有存在实际可用的原料时才提供生产工作。材料预算会放慢资源受限聚落的住房与人口扩张，地理、供给和通信仍然限制发展，不能保证每个聚落同步完成所有研究。

## 功能变更应继续满足的验收场景

这些场景表达产品行为，测试实现可以随代码重构变化。新增机制还应说明玩家从何处观察、如何干预以及如何保存恢复。

1. 远处聚落的库存改变后，未收到新消息的居民仍依据原有认知决策；接收到报告后，其选择与解释发生可验证的变化。
2. 消息通过实体递送或有效设施到达；改变道路、阻塞或通信连接会改变到达结果。转述保留来源与时效，同一报告不因重复转述增加政治票数。
3. 对同一议题改变制度、相关职业或可信度，能影响实际政策选择，并展示对应依据；不能只改变说明文字。
4. 建设、工作、运输、进食与魔法造成可核对的位置、库存或状态变化，不能出现远方凭空供给或退回货物。
5. 编辑目标、记忆或结构化经历会影响后续选择；既有世界事件及他人已收到的旧消息保持原样。无效输入不破坏当前世界。
6. 改变国家文化不批量改写居民种族或认同；迁居、分裂和领土转移后实体关系仍有效。
7. 关闭新魔法发展时阻止新的相关入口，保留已有能力及已开始项目的当前语义；不能把开关实现为清空成果。
8. 切换工具与刷新状态不使核心控件跳动；日志筛选、居民编辑及触屏手势通过真实交互核验，查看界面本身不改变世界结果。
9. 同一版本在移动、运输、传讯和研究途中保存后，恢复继续模拟与不中断的结果一致。旧版、未知格式和无效当前格式有清晰失败反馈。
10. 发布产物能在 Pages 仓库子路径加载并运行；桌面与手机尺寸交互、连续运动和存储均以实际浏览器检查。规模及设备性能以测量记录为准。

### 当前限制与更远方向

当前记忆、个人经历、亡者档案和世界日志都有容量边界，不提供无限人生历史。撤销只有当前会话中一轮编辑前的恢复点，继续模拟后清除，不是逐笔、多级或跨会话撤销。局部导航、运输、议事、发展规划与战斗均为简化规则，不保证复杂地形下的最优路径或真实社会预测。

更完整的宗教、文化传统、社会思潮、外交、战术、海战、现代军种、铁路、电网及完整奇幻体系属于后续方向。科技与魔法不强制融合。多人联机、在线语言模型、云存档与完整自由文本指令理解尚未实现，也不因列入未来讨论而成为当前交付承诺。

后续优先完善已有古代生产、交通、政治、战争的平衡和因果解释，持续验证规模、长期运行及真机表现，再增加更大内容体系。真实 Android / iOS 设备与不同浏览器的支持程度，必须根据[验证记录](verification.md)判断，不能用桌面内核或手机尺寸模拟推断。


### 第三轮剩余功能：战争与故事观察

2026-10-02 用户通过同步问答选择补齐第三轮剩余功能，战争首批采用“有限占领与防御”，随后明确授权实施。

- **有限目标**：自主进攻使用首都实际收到的聚落地址；防守军令在宣战消息送达后形成，目标为本国首都。玩家直接编辑外交时，所选第一国进攻、第二国防御，仍需当地集结。进攻军队不会自动改打附近另一处聚落。防守军队只根据附近观察迎击家园周围的敌军。
- **撤退与战报**：占领既定目标、兵员降至初始六成、军粮耗尽且饥饿、低士气、连续受阻或长期作战会终止本次任务；收到停战命令也会返乡。兵员比例、120 日受阻、720 日作战上限及恢复期 360 日是本批工程默认值。见证者携带战报，机构实际收到后才记录战果及启动恢复；开启自主停战时据此发布停战命令。军队现场结果与国家已收战报分别显示。关闭自主停战可保留外交战争状态，旧军令不会重新征募同一轮军队。
- **现实资源与恢复**：沿用实际军粮消费、抵达仓库补给。返乡归还当地军粮；无仓库时只有在场退伍者接收余粮。恢复期阻止自主进攻与新的进攻征募，收到外敌宣战后的防守仍允许。每国沿用至多一支军队，机构记录最近一次军事任务；不是多战线参谋系统。
- **因果事件**：建设开始与竣工、研究投入与完成／传播、贸易交付与结盟、军令与征募／交战／占领／撤退／战报、迁徙及分裂等路径记录实际采用的项目、消息或先前事件。没有证据时不补造因果；旧记录淘汰后保留引用并说明缺失。一个事件可有一个主要前因和至多四个补充前因。
- **聚合与关注**：相同类型、行为及参与对象的非重大事件在 60 日窗口内聚合展示，可展开原始记录；重大转折保持单条。关注多个国家、聚落及居民，居民对多人共享事件的参与从仍保留且未被玩家改写的实际经历识别；关注仅影响呈现筛选与事件条优先顺序，不改变世界或镜头。新世界、载入和导入会清空会话关注。
- **人物故事**：按时间汇集保留的真实经历、决策依据与直接相关世界事件。实际施工／研究参与者、参军、交战、撤退、退伍及迁居会留下履历；玩家编辑明确标记。仍保留最多 24 条个人经历及 256 位亡者档案。项目保存至多 32 位实际贡献者，显示的是有界记录，不声称涵盖所有参与者。
- **完工预估**：每 4 个模拟日记录实际进度，最多保留 7 个样本；至少 4 个样本且各区间速率在均值的 0.5–1.5 倍内才估算。停工、记录不足、波动或速率变化时显示具体状态；按模拟日估算，不保证现实时间。观察、采样与已保存的随机序列无关；样本随当前格式存档恢复。

新增验收：战争或报告途中保存后确定续演；远处战果不能即时改变首都认知；旧军令不重复征募；目标失效不改打邻近聚落；聚合不删原始事件且不跨对象；关注和时间线不修改暂停世界；稳定工作得到预估，停止工作或改速率后预估失效；非法新状态及旧格式导入不污染当前世界。

## 近景观察与自由编辑（2026-10-02）

本轮明确需求：居民劳动影响地形，灾害、战争和魔法有可观察动画，扩大文字池和缩放上限，增加近景模型、行动轨迹、信息折叠与编辑自由度。

- **劳动与地貌**：采伐使森林资源减少；资源不足 25 时显示树桩，完全耗尽后转为草地，木材进入实际劳动者随身库存。工坊附近的木材采集也走同一耗尽处理。居民施工竣工或玩家赐予完工建筑会清理该格森林；基础创世设施仍是初始条件。适宜的未占领地块可以通过缓慢的年度植被扩散重新形成森林，也可用地形笔刷重植。
- **事件呈现**：火焰摇曳、烟气、陨石拖尾与撞击波、战斗交击、治疗标志、丰饶/护盾光环与魔法弹道来自实际执行的动作。干旱、疫病、伐木和竣工有短暂扩散/碎屑提示。陨石是玩家工具，实际把范围内可通行地格改为低肥沙地，清除资源与道路，点燃地格并损伤居民、建筑；撞击效果是已提交结果的视觉呈现，不是延迟执行伤害。自然灾害仍从火灾、干旱、疫病中选择。
- **镜头与模型**：缩放上限从 7 提高到 24（相对于地图原始绘制单位）。概览保留批量轮廓，3 倍起增加种族体型、年龄体型、职业装备、衣发变化、步态与劳动动作、施工阶段；7 倍起增加面部、建筑细节及多种树冠、草木和岩石纹理。仅细画视口附近内容。
- **命名**：四个种族分别有 32 个名字，与 32×32 姓氏部件组成每族 32,768 个候选名；居民生成时避开现存居民、亡者档案及玩家已有姓名。地名有 512 个候选词干，生成国家与聚落名称时检查重复。种子和稳定编号决定候选顺序，不消耗额外模拟随机数；玩家仍可自由改名，已有名字不批量重写。
- **行动预览**：选中居民后默认显示其当前目标下最多 24 格的虚线路径，可单独关闭；复用实际局部移动算法，避开不可通行地格和火灾，并在模拟刷新时重算。预览不推进世界，不预测之后的新目标、突发危险或通信结果；军队成员由军令统一调动，不显示个人路线。
- **信息层级**：居民姓名、生命/饥饿、目标与干预入口常显；身体库存魔法、性格记忆、决策记录和履历分别折叠。展开状态在当前界面会话内保留，定时刷新不重建面板、不重置展开和滚动。地格详情增加当地建筑生命、施工进度、人数和最近工作时间。
- **编辑与规则**：地格详情可直接编辑资源（0–1,000,000）、肥力（0–100）、道路（0–3）；先整体校验，拒绝不可通行地格铺路，沿用本轮编辑撤销。新增自然资源再生和火势蔓延开关、采集速率与军队战斗伤害倍率（0.25–3），随存档保存。关闭再生不删除资源，关闭蔓延不熄灭已有火；采集倍率仍受实地资源上限约束。自然恢复不削减玩家赐予的超额资源。

上述动画共享暂停呈现时钟：暂停时冻结，编辑释放后可看到初始效果，继续时间后播放完整过程。短暂动画通知不属于世界存档；载入或撤销不会重播旧的施法、交战和陨石，但仍按实际地格显示现存火焰。模型差异只是外观，不额外提供生产或战斗能力。

用户选择推进近现代与未来，并明确科技和魔法不互斥、避免过度融合。同一聚落可同时发展两条路线，但不要求以魔法解锁工业、不用工业动力代替施作者魔力；普通粮食、木材、石材、矿石可共用。

自主规划可启动满足条件的研究与设施，但推进仍依赖材料、劳动力和魔法人才，不保证每个世界或聚落到达终点。关闭新的魔法发展阻止新魔法研究、设施与训练；已有知识、已开始项目及合格施作者的既有生产能力保留。本批不包含现代军种、铁路、电网、星际探索或完整奇幻社会体系；两条路线的长期平衡还需继续测量。

## 信息密度、输入与发展方向（2026-10-03）

选择摘要优先显示职业、实际任务、生产内容或可采状态。人物、建筑、地块详情只保留对象相关内容与返回／关闭；世界导航留在概览和全局名单。对象名称后不自动附坐标，定位由按钮完成。无火灾、无道路、无矿藏等常规空值不占据地块前排；土地归属和通行参数放入次要折叠区。事件等级、完整日期和国家可同排，以明确标签和间距区分，禁止点分隔。资源摘要也按自然字段紧凑排布。旧存档姓名和历史中的旧点分隔只在显示时转换为空格，保存数据保持原样，显示后的姓名可直接搜索。

居民名单默认仅在世者，每页 20 人；“包含亡者”允许查看保留的生平。搜索框保持同一控件，输入合并处理，后台刷新不清空输入。浏览器补齐 Android 软键盘仅发送 `beforeinput/insertText` 的路径，并保留正常输入法合成和实体键盘路径；编辑文本时空格不控制暂停。

国家可选择依文化自动发展、科技发展、法术传承、魔法工艺或兼修。自动模式在魔法发展关闭时选择科技。独立国家继承原国家的发展选择；既有研究和建筑保留历史。科技路线自主优先基础农业／物流、工业和能源，不要求魔法设施；法术传承优先奥术知识和施法训练，不要求魔晶生产链。魔法工艺与兼修才自主选择晶体及符文设备。

规划器先预留下一项研究或生产设施的物资，住房和拓荒不得抢走同一批材料；时代项目受材料阻碍时，不转而把预留物资花在可选设施上。伐木和采矿优先本职任务；勘察沿既定方向分段推进，补给后换方向，矿工也可寻找已掌握研究对应的燃料矿藏。仍须亲眼发现、实际采集、运输、施工和研究。百年晋升以真实冶炼和生产记录验证，不以计时器自动赠送科技，也不保证灾难或灭亡中的每个聚落都抵达终点。

## 地块、时代资源与基础运输（2026-10-02）

本轮按用户要求完善现有系统；同步问答确认包含基础航空运输，不扩展家族继承或全面征服。

- **实地改造**：农田完工标记耕地并清除该格森林；山路和桥梁可从相邻陆地施工。桥梁限河流、湖泊和浅水，山路限山地，需驿路运输研究；正常建设消耗当地库存并等待劳动。居民遇到眼前阻路地形可发起可负担的项目，同聚落一次只自动安排一个未完工项目。宽河需要逐格延伸，桥梁毁坏会恢复阻水。
- **地形与产出**：提高山地判定阈值以减少覆盖，并将每片四邻连通山地限制为最多 32 格，其余转为丘陵。普通人不能穿越原始山地，山路的步行耗时系数为 3.5；飞机可越山越水。地块详情显示产出、肥力、自然资源、累计实际采收、最近劳动日与环境影响。
- **阶段矿藏**：煤在工业冶炼后、石油在电气化后、稀土在先进计算后才能由附近矿工发现和开采。矿藏开局存在；玩家默认按世界中最新已完成研究阶段显示，也可显示全部种类与余量或关闭矿藏显示；不可再生，产物先随身携带，再返仓。地格的发现标记服务上帝观察，远处居民仍须具备研究并亲临勘探，不借该标记获取远程资源知识。无线信号塔需要电气化与信号网络，直接赐予也不能绕过时代限制。
- **舟船与航空**：船坞与码头分别建在靠自然陆岸的水域，人员从相邻岸边工作；船坞在驿路运输阶段使用随身木材制造舟船，码头提供附近舟船速度服务。航空工场在航空运输阶段制造飞机。信使／商旅从出发仓库借取实际载具；舟船可水上行驶及陆地搬运，飞机可跨越水面、山地，航空出发时支付往返石油。交付和载具归还必须到达可落脚的聚落陆地。当前是由居民携带载具的基础运输，不含独立舰队、跑道网络、航线调度或现代军事。
- **运动与观察**：每次移动按照完整的模拟耗时持续插值；选中圈、通信／运输标记、命中与跟随使用同一显示位置。暂停、变速和同 tick 的只读刷新不能重启动画，劳动与交付等待已开始的移动真正完成。伐木工和矿工从仓库备足较远采集往返的口粮。

实现选择与验证见 [ADR-0014](decisions/0014-land-and-transport.md) 及 [验证记录](verification.md)。


## 城镇、资源争夺与观察优化（2026-10-03）

用户明确要求发展不能长期停滞，至少在开局一代居民全部死亡前有实际进展；死亡须有确定原因。允许精简开销大而模拟收益小的内容。本轮实现保留实际劳动、运输和有限认知，以基础项目优先级、持续目标和实地勘察解决停滞，不直接赠送研究成果。

- **聚落名称与中心**：名称按已完成的村／镇／城等级变化。升镇保留 60 人门槛、升城保留 160 人门槛，并增加独占陆地、材料和施工要求，人口下降保留已取得等级；具体规则见下方本轮扩充约定。每个聚落有唯一实际城镇中心，迁址时随家园移动，损毁后留作重建项目。中心建筑升级独立于城镇扩充。命名不默认追加坐标；同聚落同类建筑需要区分时才在名称中使用坐标，位置仍可作为独立字段。
- **资源与冲突**：国家只依据当地库存和已经收到的对方粮情调整资源压力，双方缺粮增大敌意，双方充足改善关系。个人冲突需双方亲临同一现场、饥饿且已知当地缺粮；从争执到对峙再到斗殴，见证者逐步加入群体。离开现场或食物改善使紧张下降。城市级冲突表示参与范围扩大，尚无独立内战军队或领土占领机制。
- **逐步宣战**：自主外交须积累敌意、持续争端且满足本方人口、补给和恢复条件，争端持续至少 180 模拟日才可能宣战。国家编辑中的直接外交决定仍可立即宣战，随后征募、行军和前线消息继续按实际过程执行。
- **持续活动与发展**：不重复覆盖相同目标与工作进度；没有职业岗位的成年人可协助实际施工或其他可用工作；独居者不会因没有交流对象而持续放弃可用工作。伐木工找不到可见材料时实地勘察，远行前与补给不足时返仓。农业与基础交通研究优先于可选设施，避免长期被材料支出挤占；仍不保证每个地理条件下都完成未来科技。
- **详情与控制**：居民分行显示当前动作（包括生产取料、送往设施和条件受阻）、后续打算、理由、年龄／种族寿命、体力／上限和需求，提供休息、返乡、恢复自主、治疗按钮。建筑打开独立详情，说明功能、状态、施工、配方、运营条件和现场人员，支持修复、赐予完工、停用和恢复运营。地块显示具体产出、采收、肥力、灾害、通行与动物容量。概览的建筑／道路列表提供搜索、分页、详情和定位，并可在地图突出显示。
- **有意义的编辑**：身份名称仍可改；目标、记忆和经历的无效文字输入移除，改为任务、事实类型／来源／数值，以及经历类型／强度选择。说明指出学习、困苦、善意等如何改变人格；编辑现有描述不被当作世界指令，不重算过去。
- **动物生态**：31 类动物按地形、供水、肥力、剩余资源、耕作、聚落、干旱与火灾计算容量；按地图规模分区，每日最多复评 256 格，完整周期至少 6 日（见本页格式 12 约定），进行有界 S 型增长、邻格迁移与渐进死亡；适宜但超出容量的地块仍可迁入，容量影响后续生存。迁入邻区立即生效。同格可以多种共存，共享食物压力；按群落保存连续数量，避免为每只动物运行独立代理。3 倍近景按种类绘制图标，数量相对容量越高，图标由 0.25 倍增至 1 倍；居民可以到场狩猎可食动物，或在实际河湖岸边捕鱼，产出扣除实际动物数量。
- **上帝观察与工具**：玩家可选择研究阶段、全部或关闭矿藏，并分别开关煤、石油、稀土图标；选择只改变界面，不教会居民采矿。工具固定八个槽位并分页，空槽禁用但保留尺寸。鼠标的范围、位置与失败提示画在地图上；触屏确认条浮在地图内，预览不再推挤工具栏。
- **具体死亡原因**：记录最后造成致命损伤的原因，如饥饿、衰老、火灾、疫病、战斗、魔法、陨石或局部冲突，不把多种可能原因拼成一条死亡说明。原始原因及发生日进入亡者档案与生平。

新增验收：人口跨阈值不会代替付费城镇扩充，聚落迁址后中心唯一且可保存；稀缺需经过多个阶段才出现暴力，补给后平息；动物接近容量并迁移，改成不适栖息地后逐渐减少；观察资源与动物不改变存档／随机状态；工具跨页与触屏预览不移动核心入口；多个 256×256 种子在 1,200 tick 内且开局一代消失前完成实际研究，长程保存后确定续演。测试结果与限制见验证记录。

信使、商人和代表尚未知道外地地址时沿眼前可通行土地寻找聚落，目标记为实地探索；材料勘察与路线探索在详情中分别说明目的。探索期间保留未完成的目标，遇到危险、饥饿、疲劳时重新评估。

## 紧凑控制、地图辨识与共存资源（2026-10-03）

界面文字优先说明当前状态、操作条件、费用和后果；删除重复信息及与玩家操作无关的实现术语。研究选项首次打开即显示用途、前置和材料缺口，并随当地状态刷新；设施建造按所选类型说明用途、知识与种族条件。另建村庄的完整条件保留在折叠区；人口、库存、发展目标和进度直接可见。统计须标明本聚落或全世界范围，矿藏显示须说明不会改变居民知识。

按 2026-10-04 截图反馈进一步约定：功能只描述一次，不叠加静态用途、加成模板和重复的生产状态；正常状态不补“结构完好”“完工且健康”等套话。所选建筑自身的名称、等级及“升级完工后”不作为重复来源列出；政策、法术、其他对象带来的效果仍保留可辨识来源和剩余时间。下一级是数值预览，不标作“当前未生效”。受阻提示必须写实际原因、阈值或所缺研究，不使用“需要完工、健康与运营条件”等笼统模板。耐火细节、位置与工作记录折叠，实际阻碍保持默认可见；无需值守的设施不显示空工作人员列表。

建造表单在提交前使用实际建造校验，随设施、坐标、桥梁参数及赐予选项更新受阻原因；预检查只读。升级与改向分别展示居民施工和直接赐予的条件，达到 3 级后仅显示满级说明与关闭入口，不再预告不存在的 4 级、列出升级材料或提供无效操作；桥梁说明保留施工期间的原通道，完工后才改变等级或方向。

按钮内容水平、垂直居中，普通操作最小高度 30 px，横向各留 2 px，连续按钮之间至少 4 px；图标按钮统一为 30 px，图形为 14 px。折叠标题最小高度 30 px，展开内容留白为横向 6 px、纵向 4 px，内部条目间距 3 px。尺寸为当前工程参数，可以随触屏可达性反馈调整；折叠内容仍跳过重复计算。

建筑详情在名称后直接显示生命值；低于 50 / 100 时另行说明功能暂停、须修复至至少 50，正常生命值不加同义评价。修复后立即更新，不把判断原因藏在折叠区；桥梁、山路已铺设通道的通行状态按实际地块判断。地图近景也为受损建筑绘制生命条。功能说明、实际在场人员和操作仍来自真实建筑状态。

居民近景按种族改变体型、肤色、耳形、胡须或獠牙，按职业显示斧、镐、锤、锄、书、信件、盾剑等工具；行走、工作和休息使用不同姿态，5 倍起用小标记表示实际行走、劳动、休息、进食、交谈、学习、施法或交付。建筑按用途绘制造型与标识，定期按当地多数居民选择木框、尖顶藤蔓、石砌或兽人木桩风格；5 倍起可显示建筑类型名称。概览提供可折叠的图例与资源说明。

相邻丘陵、山地连接山脊，水域衔接河岸与河流纹理；河流动画使用呈现时钟，暂停冻结，不改变地形或消耗模拟随机数。地形纹理仍按分块缓存，不逐帧生成。

高建筑允许图形超过一个地格，近景按底部位置与居民、舟船交错绘制，后方人物被遮挡、前方人物正常可见；排序使用实际插值位置，行走跨过建筑时连续切换前后关系。飞机保持在上层，选中圈和文字在最终图层可见。点选屋顶选中实际建筑并高亮其占地，连续点击仍能切换被遮挡对象与地面；当前是平面地图上的视觉高度，不引入建筑楼层或三维碰撞。

动物迁移可以进入已经有其他种类的适宜邻格；各物种按容量及共享食物压力增长，超出容量或栖息地不适时渐进减少。3 倍起按种类分别显示缩放图标，同格按六种体型／食性组合各显示一个代表物种，详情列出全部物种；单个图标最大宽度为地块的 35%，透明背景保留地貌。乔木、灌木、草本、芦苇和作物同样在近景显示，地块详情列出种类与覆盖度；植物表示已有共享自然资源和耕作状态，不额外凭空增加可采库存。动物、植物和建筑名称可分别开关，只影响玩家观察。


## 实地占领、饮水与升级（2026-10-03，格式 9）

- **简单占地**：玩家投放及自主城镇创建时只有中心及实际建成的创始设施占地；默认示例部落按格式 12 规则预占三格半径。人口只提高可占领的最大曼哈顿距离（6–17 格），不批量改写周围地块归属。建造者在没有优先施工任务时，从亲眼可见的相邻边界选择无主或同国、尚未登记的可通行地块；走到该格后驻留 3 个模拟日登记。其他聚落居民占据现场时不能登记。自主拓荒队同样须抵达并驻留后登记新中心。上帝绘制领土属于明确的玩家编辑。
- **升级与改造**：所有建筑可升至 3 级；玩家可安排付费施工或直接赐予完成，自治规划在有材料余量时升级近期工作的设施。生产、研究、训练、治疗与中心休息效率每级增加 25%，岗位增加 1；驿站每级提高信使速度，信号塔每级增加接入和塔间范围。材料从当地仓库扣除，升级进度由实际到场劳动推进，升级期间暂停岗位生产。桥梁保留旧通道，直到新等级或方向完工生效。
- **有方向的桥梁**：仅支持左右或上下，步行路径的起点和终点桥段都须匹配移动方向。1／2／3 级桥段离选定轴向的自然岸最多 2／4／6 格；已完成桥段不能充当新的自然岸。桥段必须沿所选方向连接陆地或同向成桥。升级延长离岸上限，改向另行付费施工；暂未加入斜桥。
- **生存与实物补给**：成年普通居民每日消耗 0.04 食物、0.025 水，儿童更少，兽人粮耗略高。缺口时饥饿增加 0.8、口渴最多增加 0.6；疲劳增长减慢。出发补给从仓库实际扣除，物资随居民移动，返乡保留口粮和饮水再交付余量；普通采集者根据保守返程需求提前补给，不凭空发食物。饥饿与饮水规则可分别关闭。
- **取水与地形**：按 2026-10-04 用户补充，河、湖为无限淡水源，不受共享日额度或干旱减水影响，须到岸边打水并携带返仓；每人每次取水最多 1 份，随身库存与实际运输仍有限。详情显示“无限”。自然生成的湿地与其他陆地统一按降水与岸线供水确定日额度，干旱降为五分之一，不积累未用额度。地形笔刷的湿地仍使用每日 1 份的编辑预设。生成时一次多源 BFS 计算河湖距离，以独立噪声为供水基础，叠加高斯距离影响；土壤肥沃度使用独立噪声。存在高肥力、低供水的“旱原”地形，水源也影响森林与湿地分布。绘制新水域或日常模拟不会重新计算周围地块的生成供水值。
- **生态节奏**：动物按格式 12 的固定每日工作量分区复评，完整周期随地图增大；间隔内的繁殖、死亡和扩散按周期调整并限制单次损耗。植物覆盖另存为乔木、灌木、草本、芦苇，每格每 120 日更新一次；按行错开，避免年末整图停顿。缓慢扩散可让适宜的未占领土地重新形成森林，覆盖对应原有可采资源，不产生另一份库存。
- **观察与图标**：角色、地块、建筑详情列出当前加成、减益、来源和剩余时间，并说明未生效条件。建筑主详情直接列出提供的加成与等级。近景工作图标按真实目标显示伐木、采矿、耕作、取料、运输、打水、狩猎、捕鱼、占地、升级等，并分别表示冶炼合金、制造动力单元、精密制造、造船、制造飞机、凝炼魔晶、符文种植、以太转化；移动保留任务图标并加短线，地图图例提供名称。

首次编辑的完整撤销恢复点和文件导出采用分段异步序列化，暂停模拟以保留同一日序，准备期间镜头仍可平移。格式与模拟版本升级为 9，不迁移旧 alpha 存档；新增因果状态参与校验和确定续演。单个存档上限统一提高为 64 MiB，以容纳供水、覆盖与大人口认知记录。

## 生存补给与渐进灾害（2026-10-03，格式 10）

示例开局选择近水、能够采食的营地，家庭出生在营地相连陆地，每人从仓库领取相同初始口粮与饮水。角色仅选择局部通行检查可达的资源，不反复奔向河对岸；饥饿时先采食，可打断寻水与迁徙。实际到仓先进食、再判饥饿损伤，旅行补给保留公共当日餐食。丘陵、雪地等按自身较低食物产出允许现场采食，不能将高肥力等同于所有地形都高产。

灾害范围用于选择起点。火灾先产生 1–3 个火点，按八日间隔、相邻地块及可燃性逐步传播，自然燃烧持续 60–90 日。正常湿地不燃烧，干旱后少量可燃；当地木质建筑仍能着火。水域、沙地、雪地和山地不提供地形燃料，建筑另按用途与等级计算可燃性、灼烧损伤，升级改善耐火性；详情显示实际系数。

健康且有饮水的成年居民可赶到安全边缘持续扑救，真实扣除饮水和劳动；同格每日扑救最多额外缩短两日火势，不能因堆人或重复点击瞬间灭火。疫病先出现少量病例，通过实际同格或邻格接触逐步传播，每六日错峰检查；每日疫病伤害为 0.2，康复免疫 180 日。工程参数与原因见 [ADR-0020](decisions/0020-survival-and-gradual-disasters.md)。

## 地理、种族适应与食物链（2026-10-04，格式 12）

本节落实用户的地形生成需求，并替代前述生成、默认部落与七类动物的旧约定。同步问答确认：生态承载量决定物种是否存在，水域生成水生动物；默认部落六格欧氏半径全为本族宜居地，初始三格半径归属该部落；矮人可以直接穿行天然山地；混合聚落由本地成年居民解锁不同种族设施。功能完成后的独立调查发现生态是主要热点；用户随后同步批准大幅改变生态行为，要求当前设备生态每模拟日低于 1 ms，并补充植物可以按年更新。下面的固定每日工作量与稀疏群落复评是当前规则。

海拔独立生成，只用于区分海洋、陆地、丘陵、高山等生成结果，不参与之后的移动、劳动、选址、通信或绘图高低效果。河流沿以海洋为根的排水路径生成，洼地仍有出海路径；山脉连片上限为 32 格。上游一格小溪可步行，移动成本为 2.5 再乘种族适应系数；两三格河、四五格江需桥或船。转弯、汇合处可能局部变宽。小湖保持独立；河流经过湖泊后继续沿排水路径通海。

每格保存独立降水（每日供水单位）和肥力。生成供水是降水加上按河湖距离衰减的岸线补水，依据海拔、肥力、供水选择 23 种地形，新增小溪、江、草甸、疏林、雨林、稀树草原、灌丛、冲积平原与高山草甸。模拟不重新求岸线距离；河湖无限淡水沿用实际取水与运输规则，陆地按共享日额度取水。居民比较实际水源余量与距离，当地降水已经满足饮水时继续劳动，不在低产水格无限等待囤水。

默认四部落优先寻找完整宜居范围；小图或极端种子找不到时，确定性生成四处独立宜居区域，保留当地木材和高地等资源差异。只有默认初始部落获得三格半径地盘，后续登记与拓荒仍需到场。

种族偏好改变移动和采集／劳动效率。偏好地形移动乘 0.8、生产乘 1.15；其他宜居地为 1；不适地移动乘 1.25、生产乘 0.75。人类偏草地、草甸和冲积平原，精灵偏林地与湿地，矮人偏丘陵、山地和高山草甸，兽人偏稀树草原、旱原与灌丛。可通行与宜居分别判断：多数不适陆地仍能穿行，只有矮人可未经山路穿行山脉。

| 种族 | 特殊建筑 | 实际作用 |
| --- | --- | --- |
| 人类 | 议事厅、商贸公会 | 在场工作减少附近社交需求；运营公会扩大附近当面交流并提高当地商人通行速度 |
| 精灵 | 精灵圣林、草药园 | 圣林保留林地，按奥术基础与魔法规则训练在场精灵；草药园由精灵治疗附近真实病患 |

每族两种设施都需要本聚落有该族存活成年居民；运营者也必须同族、成年并实际到场，施工可由其他种族承担。材料、输入、运输、健康、停用及等级继续遵守共同规则，不是全地图光环。

31 种动物按小／中／大与食草／食肉分类，所有地形均有六类候选；肥力与供水不足时，较大动物可以不生成。水域使用对应淡水或海洋物种，陆地使用草原、森林、高地、寒地、旱地、湿地适应规则。食肉动物仅捕食比自身大一级、同级、小一级的食草动物，容量受实际可食猎物生物量限制；无猎物时逐步减少。捕食实际扣除食草动物，多个捕食者共享猎物。动物每日最多复评 256 格，完整周期为 max(6, ceil(地图格数 / 256)) 日：32×32 为 6 日、64×64 为 16 日、128×128 为 64 日、256×256 为 256 日。群落使用当前区域及邻格快照；本区的出生、捕食、死亡与迁出按间隔调整并限制损耗，迁入立即改变邻格数量。居民现场狩猎仍立即扣除实际动物。小溪允许陆生动物减速迁移，大河阻隔。建村勘察与出发时都排除水域，能减速穿行的小溪仍不能作为聚落中心；出发时须保证全部拓荒者可通行。植物每格每 120 日（模拟一年）复评一次，按行分散到每天；绘图、暂停和插值不会触发物种更新。详情显示体型、食性、种群、降水、补水与四族适应状态；观察不修改世界。

该轮格式与模拟版本均为 12；`rain` 为必需字段，保存河宽与新增群落，旧 alpha 格式拒绝导入。工程取舍见 [ADR-0022](decisions/0022-geography-races-and-food-web.md)，实际验收见 [验证记录](verification.md)。


## 城镇连续领地、渔船与可解释任务（2026-10-04，格式 13）

本节落实本轮十项用户要求，替代上文允许在中心范围内的未占领地建造、重新打开建筑列表就开启标记的规则。普通建筑（包含直接赐予）只允许在该城镇登记且与中心连续相连的占领区域建造。船坞和码头在紧贴本城镇占领陆岸的水格建设。创始农田、工坊仅登记紧邻中心的一格；公共道路、桥梁和山路不要求建设者拥有土地，也不凭建设改变归属。普通建筑失去占领地时暂停工作，既有材料和设施仍可查看。

领地必须有城镇，按四邻接连到本城镇中心。水上设施占地只作为陆岸附属，水格之间不能充当领地连接通道。领地笔刷从目标国家的既有城镇边界连通扩展；远处孤立笔刷不产生领地。迁城、删城、转让与陆水转换后重新修复连通性，断开的地块释放国家与城镇登记。存档校验拒绝游离占领区。领地修复不为居民提供新知识。

城镇每 30 日平衡当地非军队成年人职业：少于 16 人不设普通信使，之后每 80 人最多配置一位（向上取整），额外代表回到生产职业。主动玩家任务、在途递送、乘载具任务与最近换职居民受到保护；普通代表不自主探索或做无必要的外地拜访。信使携带可靠的新消息才再次拜访，探索须有口粮、较低疲劳且离家距离有限。职业比例与门槛是本次工程参数。

居民会保持仍可工作的采集、施工、研究和训练目标；返程保留至到家或 240 日，休息至疲劳降到 8 再重选。危险、饥渴、疲劳、资源枯竭、工作失效和阻路仍能打断。日供水比较使用实际剩余额度，避免多人在已耗尽水源反复等待。任务图标、原因与目标仍可查看，高亮能查看地图上的当前任务。

森林、疏林、雨林木材基础系数分别为 0.70、0.45、0.90；食物按地形规则与肥力、干旱计算，不把高产地都截为相同产量；石材与矿石按本格及邻近山地的产量和构成计算。种族适应与居民生产状态另行乘算。

新增渔民职业。沿岸有可食水生动物、成年劳动力至少 8 人的城镇会配置一位渔民；岸边仍可捕鱼。掌握驿路运输且仓库已有舟船时，渔民从家园借一艘真实舟船，航向六格视野内实际可达的鱼群，在水面劳动消耗鱼群，满载或需要补给时返乡交付鱼获并归还舟船。船坞造船、舟船搬运、借用和返仓沿用真实物资，不赠送或远程结算；海上存档继续同一旅程。

地图高亮有关闭、粮食压力、货物消息、通信网络、道路建筑、城镇占领区域、饮水水源、肥力、火灾干旱、捕鱼舟船、居民任务十一项。建筑列表只在首次进入时默认开启；关闭后重新进入保持选择。高建筑屋顶覆盖另一格建筑时，点击该格先选该格建筑；空地上的屋顶仍可选真实建筑，重复点击继续循环。煤、石油、稀土分别画成煤堆、油井、矿晶，替代地块角落不明含义的圆点。

地格日常详情不再出现“未取用的水不累计”与“水道宽度”等实现说明。世界概览的“玩法说明”集中说明有限供水、河流尺寸、建造、捕鱼和地图图例。所有标记、说明、筛选和点选只读。该轮格式与模拟版本均为 13，拒绝旧 alpha 世界。理由见 [ADR-0023](decisions/0023-connected-town-work-and-fishing.md)，实际证据见 [验证记录](verification.md)。

## 城镇生效、建造决策与模拟修正（2026-10-04）

- **生效与升级**：25 格连续登记的本城镇独占陆地，等价于曼哈顿半径 3，才启用城镇等级的休息、研究、信使与交谈加成，以及中心等级的休息加成。面积不足保留等级并暂停加成，仓库和补给仍可使用。升级需 `ceil(最大占领半径 / 2)` 的完整菱形等价面积，保留 60／160 人、材料及到场施工；最大范围增加或失地导致面积不足时暂停扩充并保留进度。
- **领地外采集**：食物、木材、石矿、时代矿藏、设施邻格采集、狩猎、捕鱼及主动取水速度 ×0.50。按实际资源来源是否登记给劳动者的本城镇判断，同国其他城镇不共用。动物、自然资源和水源按真实采收量扣除或记录，站在本城镇岸边不会免除水中资源的减速。
- **可解释建设**：自主设施、住房先确定用途，再筛选适宜、有实际资源且施工可达的合法位置，最后投入材料；建筑保存建造与选址原因，详情可见。建村的报告与出发检查排除周围不足 25 格可登记陆地的孤岛。自动桥梁排除可见陆路已能到达的场景，并检查对岸可接近实际任务的交互位置，保存具体任务与路线理由。道路仍是玩家建设命令。
- **任务与行动**：档案明确分列当前任务、任务地点、当前劳作、后续、行动依据，说明具体采收、加工、治疗、值守、占地或扩充内容。行动和说明共用到场距离，移动尚未结束不显示已劳动；停工如实显示。可见岗位检查视野内实际连通路径，未生效城镇优先占地；升级人口达标而面积不足时，建造者从日常生产转去补足登记，保留正在进行的施工。多个建造者不选同一登记目标；采集者在保守返程口粮不足时重新评估，局部寻路不重复进入已经走过的格子。
- **观察入口与手机**：城镇中心主详情显示城镇状态并提供“查看城镇信息”，其他建筑也可以进入所属城镇信息。手机展开信息面板使用扣除底部控制后的大部分高度，收起恢复较小高度；尺寸变化同步调整。查看、跳转、展开不改变模拟。
- **生态修正**：大地图捕食按繁殖实际使用的有界有效间隔计算，修复捕食继续增大而繁殖封顶导致的衰减，保留真实捕食、迁移、栖息地死亡与每日最多 256 格复评。无居民对照与多种子保存续演作为回归，局部捕猎、火灾或资源枯竭仍可减少动物。

具体取舍及调查见 [ADR-0024](decisions/0024-territory-activation-and-simulation-decisions.md)，实际结果见 [验证记录](verification.md)。该轮格式 13 新增可选的建筑规划说明，按当前格式校验并保存，不改变旧 alpha 格式的拒绝策略。


## 科技树、玩法解锁与文明发展（2026-10-04，格式 14）

科技帝国和魔法帝国是文明发展结果，不是科技名称或研究项目。当前有 40 项真实研究、58 条直接依赖；科技路线 26 项，魔法路线 25 项，共同基础 11 项。两条路线可以独立发展，也允许兼修。达成帝国要求同一城镇完整掌握对应路线，建成可运作的学舍及对应物资／能源／食品／工具／载具生产链；魔法路线还需奥术研习所。必要生产设施均须完成至少一批实际加工。医疗、军备与折跃等按当地需求建设，不再作为每个和平帝国的必备闲置设施（现行修订见 ADR-0029）。停用、失去领地、受损或研究不完整会使当前阶段退回发展中；没有另行研究的帝国节点，也没有额外的帝国产量奖励。

界面显示真正的有向科技树，按科技、魔法与共同基础切换。分支筛选保留所选分支及其所有前置，压缩空行列；节点直接连接实际依赖，选择后默认强调直接前置，也可显示完整路径。发展卡片位于树外，展示研究、设施与首批生产的进度和缺口。拖动、缩放、完整概览、定位、展开与周期刷新保持选择及视野；阅读不改变世界、时间或随机数。

## 生态、需求决策与界面精简（2026-10-05，格式 15）

此节替代早期关于独立物种上限、固定捕食损失上限、无需求设施必建和可食动物顺序的规则。现有 40 项研究、51 种建筑；科技帝国和魔法帝国仍是文明结果。

- **连续食物网**：野生动物总体容量降低；适宜食草物种分摊植物供给，各捕食物种分摊可吃的猎物生物量。固定适宜环境下，所有物种达到各自容量时，食草补充恰好替代可持续捕食，迁移没有密度梯度时停止。实际捕食压力从可持续、超过补充、种群衰减到完全耗尽连续变化，没有切换到“灭绝模式”的数量阈值或人为猎物保底。食物不足先导致食肉动物饥饿死亡，严重过量仍可能耗尽猎物。火灾、栖息地破坏和居民狩猎另有真实影响；不保证人为破坏后的永久共存。
- **真实养殖**：农业解锁牧场，工业与驿路运输共同支持水产养殖厂。农民在牧场地格捕获当地可驯养食草动物，渔民在养殖厂相邻淡水捕获鱼类，只取实际种群的一部分；不存在赠送牲畜。喂养消耗工人携带的食物与水、牧场的实际草料资源，劳动促进繁殖，收获保留繁殖群并先进入个人背包。长期缺少照料会减群。
- **按需发展**：水、食物、住房与伤病按实际缺口优先，不被无关施工或研究整体阻塞。军事研究参考本地防御政策及收到的近期敌情，铁路要求已有道路，贸易设施要求已知联系，药品与服务岗位要求实际用途。已解锁且需要的设施可先施工；缺料的可选项目不会堵住其他可负担项目。无合适施法人才时不盲目开展魔法研究。付费研究仍需已完工学舍和学者到场劳动。
- **任务与产量**：工位预约限制同时前往同一设施的人数；已领取的任务物资经过家附近时保留。工厂每趟最多领四批原料，每批仍逐日实地加工并亲自返仓；库存足够时停止新的补货。普通农田单人产量与工业／符文食物配方调整，升级参考饱和工位与实际需求，不以用过一次作为升级理由。
- **信息层次**：地格主信息只显示一个供水量；海拔与详细生态放入折叠内容。普通建筑无朝向选项；桥梁方向继续决定实际通行。选中对象的重复坐标、建造原因、距中心、领地面积及无关倍率移出主详情。列表中确有同名位置歧义、消息地址或地块编辑输入时保留位置。

格式和模拟版本为 15，建筑必需保存 `LivestockKind`、`LivestockPopulation`，导入校验可养殖种类、数量和上限；旧 alpha 存档拒绝。本轮的全研究实验使用明确的付费研究议程，包括和平时自主决策会略过的军备等研究，居民仍需实际研究、建设和运输。纯自主决策另以行为回归验证。完整原因见 [ADR-0029](decisions/0029-balanced-ecology-and-demand-planning.md)。
