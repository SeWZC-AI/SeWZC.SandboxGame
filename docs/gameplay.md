# 操作与存档

本指南介绍 SeWZC.WorldBox 的操作与本机存档。浏览器入口见 [项目 README](../README.md)，本地启动见 [开发约定](development.md#本地运行)，机制与当前能力见 [产品约定](product.md)。

## 操作

首次打开会生成带四个种族的示例世界。通过“新世界”可选择整数种子、128×128 或 256×256 地图，以及是否预先投放居民。

| 操作 | 方法 |
| --- | --- |
| 选择地格 / 建筑 / 居民 | 停用工具后点击地图，只显示简短摘要；点击“查看”才打开详情。连续点击可切换重叠对象。也可在“概览 → 居民”搜索并打开档案 |
| 关注与人物故事 | 国家、聚落和居民详情中的“关注相关事件”；“概览 → 我的关注”汇集变化，居民档案可打开人物故事。关注仅在当前世界会话保留 |
| 聚落、研究与通信 | “概览 → 聚落列表”选择聚落；详情顶部“概况 / 建设 / 研究 / 通信”切换同一聚落。概览也可直接打开“科技与魔法研究”及“消息与通信” |
| 居民定位 / 编辑 | 档案显示当前动作、后续计划、体力与寿命；可快捷安排休息、返乡、恢复自主或治疗。目标、记忆与经历用结构化选择并说明实际影响 |
| 建筑 / 道路 | 展开“工具 → 建设”，选择聚落；默认直接赐予，可切换“居民施工”。在“概览 → 建筑与道路列表”查找并定位，建筑独立详情可修复、停用、恢复运营或赐予完工；建造表单可从地图选点 |
| 工具分页 / 预览 | 工具栏用“上一页 / 下一页”选择全部地形与可放置建筑；鼠标显示地图预览，触屏确认条浮在地图上 |
| 矿藏与动物显示 | “概览 → 矿藏显示”选择已发现或已有聚落掌握开采技术的矿藏、全部矿藏或关闭，并分别开关煤、石油、稀土及动物图标；这些设置不改变居民知识，3 倍近景显示动物 |
| 制度 / 法术 | 国家档案编辑文化与制度；顶栏“规则”调整世界；研究节点或成年居民档案可打开施法表单，研究入口优先当地施法者，居民入口优先本人 |
| 鼠标移动地图 | 观察模式下左键拖动，或任意工具下右键 / 中键拖动 |
| 鼠标缩放 | 滚轮，或地图上的矢量加减按钮；最高 24 倍，近景自动显示更多细节；“全图”恢复总览 |
| 地形与领土绘制 | 选择工具后左键按住拖动，可选择小 / 中 / 大笔刷 |
| 地图标记 / 玩法说明 | 在“概览”或“道路与建筑”选择高亮或关闭；“概览 → 玩法说明”解释供水、地形、领地、捕鱼和居民任务 |
| 地格编辑 | 点选地格 → “查看” → “编辑此地资源与道路”；可改资源、肥力和道路等级 |
| 地块改造 | 点选地格 → “查看” → “安排居民改造”；河流可修桥、山地可修山路、陆地可开农田，扣除材料后等待居民劳动 |
| 居民轨迹 / 信息折叠 | 选中居民后默认显示当前目标路径；身体、记忆、决策和履历可分别展开 |
| 投放居民 / 灾害 | 选择种族或灾害，点击地图；居民数量与灾害范围分别可选 |
| 触屏操作 | 单次工具轻点先预览，再确认；单指拖动平移，双指捏合缩放；触屏绘制采用轻点笔刷 |
| 时间控制 | 点击“暂停 / 继续”，或在地图获得焦点后按空格；速度按钮选择 1× / 2× / 5× / 不限制，“不限制”按设备能力尽快推进 |
| 关闭面板 | 固定的关闭按钮或 `Esc` 返回地图；“工具”收起工具区，“漫游”停用当前工具 |

打开操作窗口和从地图选点时，时间暂时停止；取消后恢复打开前的运行状态。提交编辑会暂停世界，并保存本轮编辑前的快照。顶栏撤销图标或“存档 → 撤销本轮编辑”恢复这整轮编辑之前的世界；继续模拟后该恢复点清除。它不是逐笔多级撤销，也不保留跨会话的撤销历史。

在国家详情打开编辑器，可修改名称、旗色、库存与外交，选择古代发展水平，向首都添加指定种族，或者启用该国领土笔刷。领土笔刷覆盖聚落时，会一并转移聚落、居民、库存及相关归属；聚落独立入口在该国拥有至少两处聚落时出现。

## 存档与兼容性

浏览器存档保存在本设备当前站点的 IndexedDB 中，不会上传到 GitHub。清理网站数据、隐私模式退出、存储配额限制或更换站点域名都可能导致存档不可用；重要世界请使用导出功能保存 JSON 文件。导入会验证格式和世界数据，通过后替换当前世界。单个存档的未压缩内容上限为 64 MiB。暂停且未编辑的世界不重复自动保存。

桌面自动存档位于系统本地应用数据目录下的 `SeWZC/WorldBox/autosave.worldbox`；导入和导出通过系统文件选择器完成。

切换后台时暂停世界，返回后继续；不会按离线时间补算发展。**Alpha 阶段不承诺存档向后兼容**：版本更新可能拒绝旧世界，此时需新建世界；不提供旧格式迁移。当前接受的格式与模拟版本见 [架构说明的编辑与存档](architecture.md#编辑与存档)，存储实现见 [平台保存说明](architecture.md#平台保存)。
