# 第二轮：有认知的居民与可解释的文明

此文件保留第二轮交互式问答当时确定的目标，不作为功能已实现的声明，也不随以后每轮需求继续累加。现行行为与边界见 [产品约定](product.md)，设计原因见 [设计决策](decisions/README.md)；实际实现与检查结果需结合代码和 [验证记录](verification.md) 核对。

## 已确认的设计

- 居民根据需求、性格、职业、环境、资源、经历和已知信息形成目标。思想面板解释真实行动依据。
- 当面交流以及实体信使、商旅传递消息。远方事件不能立即进入角色或机构的认知。
- 消息保留发生／观察时间、接收时间、来源和可信度；本轮先做过时消息与来源差异，不加入随机谣言。
- 公民影响力受制度、身份和议题相关性影响；意见通过当地议事和代表递送，不能直接扫描全国居民的内心。
- 文化、种族和国家是独立概念。迁居、交流和制度可以影响文化。
- 角色属性、性格、目标、思想、记忆和历史均允许编辑。改写影响认知及后续行为，不回溯重算已经发生的世界变化。
- 本轮同时建立三组可玩的基础闭环：文化／制度／政策／研究；魔法／种族能力；建筑／道路／运输。
- 魔法采用中魔基线：并非人人精通，也不是罕见奇迹。种族影响天赋分布与擅长方向，地区魔力、研究、训练设施及资源约束实际使用。
- 远程通信科技依赖设施、覆盖和连接。科技解锁本身不带来全局即时通信。
- 完成验证后更新 `alpha`，部署到现有 GitHub Pages，并运行公网浏览器检查。
- 用户明确 `alpha` 不考虑兼容性：本轮不迁移旧存档，不以旧内部接口或布局兼容为约束。旧格式应明确拒绝，提供新建世界入口；当前格式仍需完整校验与可靠恢复。

## 交互与呈现

- 工具分类切换时，常用入口、暂停／速度按钮及工具区域保持稳定；不可用动作采用明确禁用状态。
- 可从地图选中、定位居民，查看身份、当前任务、决策原因、知识来源及历史，并进入编辑。
- 世界日志区分重大、重要、普通消息，显示清晰时间和所属国家，可筛选与定位；避免贸易等普通事件淹没重大事件。
- 居民的移动来自实际目标和路线；显示层连续插值，不能改变模拟状态。暂停、载入和编辑传送要重置或冻结插值。
- 丰富地形同时带来肥力、资源、通行、魔力或灾害等实际差异，不能只有颜色变化。

## 关键验收

1. 远方尚未被观察或传达的库存变化，不立即改变本地角色或机构决策。
2. 信使和商旅需要实际抵达；道路、阻塞、失联及通信设施影响传递。消息不能在一个步骤里无限转述。
3. 重复转述不重复计票；角色和机构使用的消息必须保留来源与时间，过时信息造成的选择可以解释。
4. 劳动、进食、运输和魔法效果对应实际位置、库存及资源消耗；不能隔空生产、供给或退还货物。
5. 不同制度、职业诉求和议题权重能产生可验证的决策差异；文化和研究产生真实效果。
6. 角色编辑、历史修改、国家分裂与领土转移保持数据关系有效；查看界面不改变世界结果。
7. 当前版本世界在移动、传讯、研究和运输途中保存后，恢复结果与连续模拟一致；旧版和未知版本存档明确拒绝。
8. 工具切换保持核心按钮位置稳定；角色档案编辑、日志筛选及触屏操作经过真实浏览器验证。
9. 256×256、约 2,000 居民场景验证模拟推进、存档大小和浏览器表现；保留真实设备性能限制说明。

本轮是上述系统的基础闭环，不等同于完整社会科学模拟、无限人生历史或全部未来时代内容。
