# ADR-0032：明确零值语义、精确稀疏种群与分块压缩保存

- 状态：采用；扩展 [ADR-0008](0008-complete-save-state.md) 与 [ADR-0018](0018-five-speed-work-budget.md)
- 记录日期：2026-10-05
- 来源：用户要求缩减存档大小、冗余与自动保存卡顿，并采用 `0.0.1-alpha.1.1` 版本号形式；以下为本次工程选择

## 背景

256×256、2,000 居民夹具的原始 JSON 为 31,133,692 字节。大量地格写出无归属、无道路、无火灾等零值，动物种群重复物种字段名；既有分段序列化仍增长完整 MemoryStream，最终整块转成字符串。后台写入不能消除这些主线程分配、解码及大字符串传输开销。

## 决定与约束

格式改为 16，模拟版本保留 15。库存缺失金额和指定地格计数明确为零；有非零初始化器、必须存在或其他缺省含义的字段仍显式保存，禁止全局忽略默认值。附加动物保存精确的编号／数量稀疏数组，不舍入或丢弃微小数量，拒绝重复／未知编号与非法载荷。

捕获直接产生 16 KiB 以内的文本块，按完整 UTF-8 码点解码文本块并按 UI 时间预算让出执行权。捕获期间暂时停止世界推进，编辑取消捕获。浏览器分块传输文本，让普通 Worker 压缩并原子写 IndexedDB；没有 Worker 或压缩 API 时有分块回退。桌面后台压缩临时文件并原子替换。落盘期间模拟继续，只有成功的完整提交才更新保存标记。

自动保存按世界实例、日序和编辑修订跳过未变化世界；保留手动保存、错误重试和后台暂停语义。编辑完成后至少延后 5 秒再自动捕获，避免较大的撤销快照耗尽取消重试期限后立刻启动另一轮捕获；连续编辑会继续延后。压缩前与解压后的内容上限均为 64 MiB；导出仍为 JSON。应用版本采用 alpha 迭代号后附修订号的形式。

## 原因与代价

省略确定的零值和编码重复能降低体积而不删除居民记忆、历史或中间任务。分块捕获与分批传输避免一个大缓冲增长、整体解码或单次 WASM 字符串传输占住 UI。gzip 增加后台计算，但减少实际存储大小与 IndexedDB 复制；捕获仍需要短暂停留，以保留同一模拟日的一致快照。GC、渲染或单个实体序列化仍可能造成设备相关峰值，不能保证所有硬件完全无卡顿。

## 重新评估条件

如果真实手机仍受捕获停留或 GC 限制，再评估不可变快照、写时复制或全模拟 Worker；这些方案需要覆盖全部命令与世界修改边界，不在此次引入。新增库存字段或物种须同步零值语义、转换器与完整续演验证。

## 实现与验证

核心：`WorldEngine.Persistence.cs`、`WildlifePopulationsJsonConverter.cs`；UI：`MainView.cs`、`MainView.AsyncEdits.cs`；平台：`BrowserWorldStorage`、`storage*.js`、`DesktopWorldStorage`。验证涵盖精确微小数量、全部物种、非零初始化器的合法零值、未知／重复编号、取消、未变化跳过、失败重试、确定续演与真实浏览器保存／刷新。实际结果及设备限制见 [验证记录](../verification.md)。
