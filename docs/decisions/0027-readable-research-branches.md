# 0027：两条帝国路线分别成树，支线独占位置

状态：采用。日期：2026-10-04。来源：用户指出首版连接图仍难以读懂。替代 [0026](0026-connected-research-graph.md) 中将 24 个节点混排在一张图、在外围绕长连接、默认高亮所有祖先的呈现选择；保留真实连接、拖动、缩放与只读边界。

## 原因

按最短依赖深度居中排列会使短支线的成果留在顶端，帝国终点需要大量跨层外围连线。两条路线叠加后，这些线环绕主干；即使连接正确、节点不重叠，仍难以辨认发展次序。全祖先高亮在选择终点时进一步放大密集连线。

## 选择

科技、魔法及共同基础分别成树，用直接按钮切换。科技按民生、研究方法、工业能源、运输制造占据固定位置，魔法按民生、奥术修复、符文以太排列。每条终点支线独占一列，其成果直接向下，在底部同一条汇合线连接，用接点与「全部成果汇合」说明所有前置都需要完成。实际研究依赖画为曲线实线；帝国成果汇合画为较细虚线，不能在节点外围绕一圈，也不叠出多条平行长线。

选中默认只高亮直接前置，顶部同时给出名称；完整祖先路径由明确按钮开启。视野过滤保留全部实际知识和每条依赖，两条帝国路线的连接并集必须与 Core 的 39 条关系一致。固定排位是 UI 选择，新增研究时须同步调整支线位置，并通过线路不穿过节点的检查；不改变研究前置或居民认知来适应绘图。

## 输入与验证

从节点拖动时，按钮先失去指针捕获，其冒泡事件不能取消科技树刚获得的捕获；只有科技树自身失去捕获才结束平移。浏览器用真实触摸事件检验连续拖动，缩放、过滤和阅读继续保持存档一致。结构检查约束真实连接覆盖、节点不重叠、线路不穿越节点与终点不绕外围；可读性仍需检查实际桌面／触屏画面，不能用结构测试替代。

实际验收与截图见 [验证记录](../verification.md)。研究及模拟规则保持不变，原双帝国存档继续有效。
