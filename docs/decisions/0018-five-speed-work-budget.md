# ADR-0018：分区生态、增量统计与可响应的保存

- 状态：采用
- 记录日期：2026-10-03
- 来源：用户要求继续优化 5 倍速，并明确允许调整算法及数值；实际热点调查见 [性能记录](../performance.md)。

## 决定与约束

补充 [ADR-0015](0015-ecology-and-escalation.md) 与 [ADR-0017](0017-readable-map-and-communities.md)：每格仍每六日进行增长与迁出，将地图按行分成六区，每日完整处理一区及邻行迁入。区内各物种读取同一初态，然后统一提交；跨区迁入立即生效。区域仅由保存的日序推导，没有待提交的生态阶段。S 型增长、共享食物压力、容量衰减和实际邻格迁移继续保留；不同版本的群落数值可以变化。

容量缓存使用归一化且饱和后的食物输入，资源超过 100 时不重复求值。领土计数由固定地格的归属变更增量维护，载入或更换地格数组时重建；这些缓存不进入 JSON。人口和真实库存仍按每日事实汇总。地形缓存只在真正改变图像的资源阈值失效，动物及植物数量继续由独立图层显示。

补充 [ADR-0007](0007-presentation-clock.md)：倍率改变调度间隔，增加下一步前预留上次地图刷新和模拟步的开销。12 ms 是软预算，单个原子步不能被中断；性能不足时实际推进变慢，不能跳过实际劳动、消息、饥饿或战争。

补充 [ADR-0008](0008-complete-save-state.md)：定期和手动保存采用有界缓冲序列化，间歇让出界面执行权。捕获期间暂缓模拟，但镜头和观察可用；任何编辑、撤销或世界替换在修改前取消捕获，保留上一份有效存档。捕获结束后不追赶暂停时间。手动文件导出、导入校验和编辑撤销快照仍有同步开销。

浏览器由普通 JavaScript module Worker 执行大小检查与 IndexedDB 写入。入口通过文档 import map 解析带指纹的 Worker URL，并传入已经解析的存储模块 URL，因为 Worker 没有文档 import map。不引入 WebAssembly 多线程、SharedArrayBuffer 或特殊部署响应头；不支持 Worker 时使用原存储路径，运行失败明确报告。

## 代价与验证

生态快照数组增加常驻内存；分区边界的提交顺序改变群落数值。保存捕获增加临时缓冲，世界时间短暂停留，最终字符串解码与跨线程投递仍可能阻塞。观察不写世界、不消耗随机数；当前格式 8 不变，同版本保存恢复须确定续演。

回归见 `PerformanceBehaviorTests.cs`、Headless UI 的地形位图与连续笔刷检查，以及 `tests/browser/saving.cjs` 的实际拖图、编辑取消、完整存档和 Worker 降级。按同一夹具串行测量实际产物和隔离探针，不把插桩耗时或动画帧机会当成真机 FPS。实际结果见 [验证记录](../verification.md)。
