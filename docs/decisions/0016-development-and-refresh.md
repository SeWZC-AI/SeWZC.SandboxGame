# 0016：发展路线和按变化刷新

日期：2026-10-03。状态：已实现，验证结果见 [验证记录](../verification.md)。补充 [独立晋升路线](0013-independent-advancement.md)，延续 [生态与渐进冲突](0015-ecology-and-escalation.md)。

用户要求百年内科技文明有实际时代进展，科技和法术社会不应被迫建设同一套魔法设备；同时手机详情拥挤而有效信息不足，软键盘无法输入，地图和列表重复计算过多。

选择国家发展偏好，并让研究、建设、住房和拓荒共享下一项目的实际物资预算。自然法术传承与魔法工艺分开，继承偏好不影响已发生的研究历史。勘察和劳动仍在角色实际视野与补给范围内完成；不通过定时赠送研究或库存满足进度目标。新增偏好允许旧当前格式缺省为自动，结果按已有文化和规则确定，不使用随机初始化；非法枚举会拒绝导入。

呈现缓存使用世界日序、可见范围、事件标识与选择作为失效条件。静态图形复用位图，动态角色在视野内插值；远景降低几何重建频率，世界时间独立。只给对象相关的详情，普通空值折叠，相关短字段同排。保留现场劳动、消息与运输，不靠删去模拟机制改善性能。

输入适配补齐当前框架没有消费的 Android 软键盘插入和删除事件。重复提交与焦点保持通过浏览器回归验证；升级框架时应检查是否可移除，真实输入法仍需实际设备复测。
