# ADR-0033：清理无现行依据的历史约束与废弃状态

- 状态：采用；取消 [ADR-0028](0028-civilization-outcomes-and-research-gameplay.md) 的空编号保留
- 记录日期：2026-10-06
- 来源：用户指出保留错误研究编号的行为不合理，经同步问答明确范围包括“没有依据却自行增加约束并写入注释／测试／文档”；另明确选择删除旧聚落等级的防守加成

## 问题与修正

删除人造帝国研究时，代码仍跳过编号 18、23，测试要求这两个历史编号永远无效，ADR 也记录了不复用选择。该约束不对应当前机制，且违背已确认的 alpha 不考虑兼容性约定。研究枚举取消两个跳号，测试继续验证文明结果不属于研究知识，不再保留历史编号断言。

`TradeRoutes` 和 `Settlement.Petitions` 只有保存、校验及清理路径，没有现行模拟生产或消费路径；居民贸易使用实际背包与目标，制度使用 `Society.Reports`。删除这两个废弃字段及 `TradeRoute`、`CivicOpinion` 类型和相关校验。

旧 `Settlement.Level` 没有晋升更新路径，常规世界保持默认值；城镇晋升实际上使用 `Tier`，列表却显示旧等级，围城防守也读旧字段。删除旧字段，列表显示真实村／镇／城；按用户同步选择删除旧等级防守加成，不自行增加城镇晋升的战斗效果。

研究数字含义与保存结构改变，格式提升为 17；防守规则改变，模拟版本提升为 16。旧格式明确拒绝，不迁移或猜测旧研究含义；当前格式仍须完整往返、校验和确定续演。这是落实现有保存要求的工程处理。

## 避免再次固化假设

协作入口链接 [开发约定](../development.md#约束必须有现行依据)：新增约束需能追溯需求、当前依赖或真实缺陷；注释、测试及 ADR 本身不能给自行假设补授权。删除概念时核对全套读写和呈现路径，问题或产品取舍不清时使用同步提问。正常的工程实现不增加逐项审批流程，规则文字也不能替代后续审查。

## 验证

研究目录及文明结果检查、当前格式完整往返和旧／未知版本拒绝、聚落列表真实等级与只读导航，以及核心集成续演。实际结果及未覆盖范围见 [验证记录](../verification.md)。
