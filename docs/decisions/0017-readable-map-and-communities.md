# ADR-0017：可辨识地图、紧凑详情与多物种共存

- 状态：采用
- 记录日期：2026-10-03
- 来源：用户要求按钮居中与横向间距、折叠区减少留白、明确建筑损伤、区分种族／职业／建筑、连接相邻山河，以及显示同格多种动物和植物。

同日的 5 倍速优化将全图生态提交改为每日完整提交一区，见 [ADR-0018](0018-five-speed-work-budget.md)。下文的共同初态约束仍适用于每个区及其邻行，跨区按日序提交。

## 决定与约束

沿用 [按变化刷新](0016-development-and-refresh.md)，居民、建筑和动作标记采用按类型复用的透明小位图；按用途绘制标识、按种族改变形态与风格，并给出使用同一素材的图例。相邻地形绘入已有分块缓存，河流用只读呈现时钟。按钮保持自然宽度、居中和明确横向间距，折叠区直接压缩主题留白；生命值与实际低于 50 的停工条件常显。

用户补充高建筑遮挡后，近景改为按实际底部位置交错绘制建筑、人物和舟船；屋顶命中、裁剪与文字顶部共用同一图形边界。可见建筑集合按变化更新，绘制排序仅处理可见对象且复用列表，飞机与选中标记保留上层。视觉高度不等于新增楼层或物理碰撞。

补充 [原生态表示](0015-ecology-and-escalation.md)：同格多种动物用值类型的七个数量字段表示，共享食物压力并按物种容量增长、迁移或死亡。计算迁移增量后统一应用，保持各物种读取同一初态。容量按精确地块状态缓存，邻格索引在各物种间复用，不引入逐只动物、逐帧生态更新或随机源。

当前格式 8 保留必需的主物种和数量，新增附加数量可以缺省为全零。默认值与初始化值一致，零值省略安全；校验非有限、负数及重复主物种，并验证保存中途继续后的完整确定状态。植物覆盖度解释现有共享自然资源及耕作状态，不增加第二份可采库存。

## 原因与代价

小位图与分块缓存使更多可辨识图形不必重复执行大量绘图指令；图例与实际状态可核对含义。多物种增加群落计算、地图内存和存档字节，容量缓存减少重复规则求值，但不能据此宣称整体模拟变快。大世界性能须独立复测，仍保留实际劳动、运输和通信。

仍没有动物捕食、狩猎或个体故事。当地多数种族定期决定建筑风格，尚无单栋建筑历史族属；今后如果建造者身份或混合建筑风格参与模拟，需要保存独立事实。
