# ADR-0023：连续城镇领地、稳定任务与真实捕鱼

- 状态：采用；补充并替代 0019／0021／0022 中允许范围内未登记建造及自动重开标记的部分
- 记录日期：2026-10-04
- 来源：用户本轮十项明确要求；具体职业配额、休息阈值与连通算法为工程选择

## 决定与原因

普通设施依附已登记的连续城镇领地，赠送不能绕过；桥梁、道路、山路是公共通行设施，建设不改变归属。水上设施必须贴近本城镇陆岸。四邻接与禁止水格串联可解释孤立土地的释放，也避免跨海占领。城镇中心是连通根，地形切断与迁城必须修复并可保存。

通过归属修订号跳过未改变的全图连通遍历；保存时独立校验。状态约束变化采用格式 13，alpha 不迁移旧格式。

信使根据成年人数配置，代表留在本地；保护玩家指定与在途任务。有效劳动与返程继续进行，恢复后再出发，生存和危险仍优先。这样减少无必要切换与往返，同时保留真实路径、取料、送达和本地认知。

捕鱼使用已有船坞、实际舟船与鱼群，在船上执行劳动并返仓。交通方式是可达性查询参数，不让规划改变事实。地图标记和玩法说明仅呈现世界；关闭选择保持，地形产量使用同一资源规则。

## 代价与重新评估

领地被切断后普通建筑暂停，用户可能需要重新连接或转让中心；连通规则不表示居民拥有全部领地信息。按人数配置职业仍是简化模型，可在有需求证据时改为递送任务容量。持续劳动也可能保留次优目标，危险、供水与失效条件必须有回归。捕鱼目前使用既有个人载具，未引入独立船员或船队实体。
