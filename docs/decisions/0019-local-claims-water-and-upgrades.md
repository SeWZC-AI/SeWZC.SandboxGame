# 0019 实地占地、独立供水与可施工升级

状态：采用。记录日期：2026-10-03。

## 背景与输入

用户明确要求缓解界面卡顿，允许算法与部分行为改变；城镇范围只增加上限，地块由角色到场简单占领；建筑可升级，桥梁限制方向与离岸距离；角色携带食物、降低生存压力；动物迁移加快而植物按年迁移；增加小湖、取水运输、可观察的真实加成。补充要求肥沃度和供水独立，生成供水叠加独立因素与非线性的附近淡水距离影响，只在生成时计算。同步问答确定包含实际狩猎／捕鱼、随身饮水与运输入仓、玩家和自治两种升级方式。

## 决定与约束

占领使用现有目标和工作日计数，角色完成移动后原地工作 3 日登记；不另加控制度、驻军或每帧全图检查。人口增加只更新上限，自主拓荒同样等待到场。创始设施和明确的上帝编辑保留直接归属语义。

饮水沿现有实物库存、运输和军粮体系保存。河湖共享每日额度，陆地供水不累积；只有实际到源地块或相邻岸边才可取水。供水位置须亲眼发现或实际获知。土壤与基础供水采用不同种子噪声，淡水距离一次 O(地图面积) BFS 后叠加高斯项，避免每天重算，也避免肥沃等同于湿润。

桥梁先支持两条正交轴，不增加斜向寻路。离岸限值按轴向自然陆岸计量，桥段不能延长岸线；升级与改向复用材料扣除、实际施工和项目观察。升级期间停止生产，旧桥的通行参数直到完工才切换。自动架桥必须保留已规划的研究和生产材料。

植物覆盖按 120 日错开更新，动物按原有 6 日分区更新但降低增长、加快迁移；拥挤栖息地允许迁入，靠实际容量与资源决定后续生存。实际狩猎／捕鱼减少对应群落数量。

加成说明和任务图标从核心真实规则查询，纯观察不能修改世界或随机序列。完整撤销恢复点保留，首次编辑先等待分段异步捕获，不能在状态被修改后补造快照。

## 原因与代价

简单到场登记能体现实际行动，又不引入大量持续计算。独立供水可以表达缺水但肥沃、湿润但贫瘠的土地；生成时固定距离场使日常模拟成本有界。升级复用劳动体系避免自动按时间赠送等级，也不增加另一个项目资源账本。

新增水、覆盖与升级状态使旧 alpha 格式不再具备完整因果状态，格式和模拟版本升至 9，不尝试补造旧世界的水源认知。平台和核心上限统一为 64 MiB，以容纳最大地图和较大人口的认知记录。首次撤销快照仍有完整序列化总成本，但通过让出 UI 线程降低连续阻塞。
