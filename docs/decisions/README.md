## 简要记录

每项区分需求来源与工程取舍；“保留”表示设计理由仍适用，具体行为可由后续记录修订。被替代部分保留原因和双向链接，原始完整正文与当时验证通过 Git 历史查阅。

### ADR-0001

**Avalonia 共用界面与静态交付。保留；2026-10-01。** 用户指定 C#／Avalonia、2D 沙盒及 Pages。Core 无平台依赖，UI 共用，平台存储接口及当前单线程／关闭 AOT 是工程选择，以支持普通静态子路径。

代价是 WASM 与字体下载、主线程预算及本地存储限制。真机证据或明确的多人／同步需求出现时重新比较架构，仍须说明如何满足静态交付。

### ADR-0002

**本地认知与实物传递。保留；2026-10-01。** 用户要求按需求、性格、职业、环境及资源行动，限制异地通信。结构化事实、目标评分与投递队列让行动可以追查，避免全知和隔空结算。

旧知识可以造成错误决定，路径受阻也有代价，须提供真实依据。新增通信、误导或物流方式时定义观察、递送、失效和费用，不伪造自由文字推理。

### ADR-0003

**制度读取已递送意见。保留；2026-10-01。** 用户要求身份、制度和议题影响政治，意见须传播。报告保留原作者并去重，依据可信度、年龄与相关性评分，连接公民、运输与决策；玩家覆盖与自治分开。

权重是简化工程模型，不是完整选举。新增制度时检验同一证据下的实际决策差异。废弃请愿字段清理由 [0033](#adr-0033) 处理，实际报告路径保留。

### ADR-0004

**种族、文化、国家独立。保留；2026-10-01。** 用户明确三者不同且可相互影响。独立身份支持混合国家、接触与迁徙，避免种族成为固定政治阵营。

代价是更多引用和界面概念。宗教、多重身份等扩展时重审文化模型；当前少量价值维度不等于完整文明传统。

### ADR-0005

**编辑影响未来而不重演过去。保留；2026-10-01。** 用户要求编辑属性、思想、记忆及历史。候选副本校验、事实修订和结构化经历，使干预可预测，已传播旧副本与既有世界结果不追溯改写。

个人记录可能与客观历史不同，须标明玩家编辑；回溯重演属于独立玩法。窗口、撤销及异步失效边界由 [0031](#adr-0031) 补充。

### ADR-0006

**常驻工具布局。被 [0011](#adr-0011) 替代；2026-10-01。** 用户要求减少按钮位置跳动，早期固定分类／槽位降低误触，却占据手机地图空间。

后续收起工具和分离观察入口，保留稳定时间控件、输入与提交可达性；固定槽数不是永久要求。

### ADR-0007

**模拟与呈现时钟分离。保留；2026-10-01。** 用户要求平滑移动。插值改善显示而不改变规则、世界随机数或只读操作；比连续物理或提高模拟频率更适合地格原型。

显示与逻辑可能存在时差，必须处理暂停、变速、载入和传送。动作特效及只读路径预览沿用此边界，完整移动时长与标记一致性由 [0014](#adr-0014) 细化。

### ADR-0008

**完整因果状态与合法零值。保留；2026-10-01。** 当前格式需可靠恢复。曾省略默认零值后恢复为非零初始化器，因此保存所有途中状态，缺失语义逐字段定义，不全局忽略默认值。

显式状态增加体积，但仅能导入不能证明续演正确。压缩取舍由 [0032](#adr-0032) 扩展，仍检查零值、往返、非法输入与同版本确定续演。

### ADR-0009

**alpha 无旧格式迁移，记录有界。保留；2026-10-01。** 用户明确 alpha 不考虑兼容性；版本及容量是工程选择。减少早期兼容层，同时用预算控制长期记录、内存和载荷。

代价是旧世界需重建、早期历史会淘汰；当前格式的正确性不豁免。稳定发布、长期世界保留需求或负载改变时再评估；错误历史占位已由 [0033](#adr-0033) 清理。

### ADR-0010

**真实浏览器输入与部署后验证。验证理由保留，自动化方案已替代；2026-10-01。** 当时用只读语义快照定位 canvas 控件，以真实输入和存储验证裁剪发布；核心与静态检查无法代替这些行为验收。

代价是浏览器噪声和验收成本。2026-10-03 改为快速冒烟与手动回归；2026-10-07 用户要求删除全部旧测试，旧浏览器脚本、快照桥及部署后检查均已移除，重新建立 xUnit 单元测试。当前 CI 范围见 [部署指南](../deployment.md#发布到-github-pages)，不将历史方案当成现行工具。

### ADR-0011

**自主文明与可收起地图工具。保留；2026-10-01。** 用户反馈停滞、工具混乱及手机空间不足。替代 [0006](#adr-0006) 常驻布局，地图工具与观察、规则分开，预览只读；发展、外交、迁徙与分裂依实际信息和过程。

增加因果状态与长期平衡成本；事件数量不代表好玩，节奏目标不靠凭空定时事件。战争与故事扩展见 [0012](#adr-0012)。

### ADR-0012

**有限战争与只读故事。保留；2026-10-02。** 用户选择有限占领和防御。单一已知目标、实地补给、递送战报及军令去重让停止和恢复可解释；故事复用真实事件、经历及项目样本。

每国有限军事记录、有界贡献者和历史，不覆盖多战线或无限人生史。扩展家族、征服或跨会话关注时重新定义状态与预算；延续 [0011](#adr-0011) 的自主过程。

### ADR-0013

**科技与魔法独立发展。保留；2026-10-02。** 用户选择近现代／未来，明确两线可并存而不强制融合。独立专属动力，共用普通资源，现场加工和运输保留实际生产意义。

基础载具不等于完整电网或交通系统。矿藏、航空及通信前置由 [0014](#adr-0014) 扩展，真实研究玩法由 [0028](#adr-0028) 扩展；当时未含铁路不代表现在未实现。

### ADR-0014

**地块改造、矿藏与实际载具。保留并修订；2026-10-02。** 用户要求土地劳动、阶段资源、桥梁和连续运动，并确认基础航空与主动打开详情。分离地形／改造，用个人携带载具实现越水越山，细化 [0007](#adr-0007) 的完整移动时长。

无独立船队、跑道或航线调度，局部导航可受阻。矿藏观察不授予角色知识；船坞／码头和选址由 [0021](#adr-0021) 修订，延续 [0013](#adr-0013) 的实物生产。

### ADR-0015

**群落生态、渐进冲突与真实发展。部分保留；2026-10-03。** 用户要求增长迁移、逐步冲突和可控制观察。连续群落避免逐只代理成本，资源冲突有现场阶段，发展衡量实际完工而非定时赠送。

早期一格单物种由 [0017](#adr-0017) 替代，生态周期与食物链后来由 [0022](#adr-0022)／[0029](#adr-0029) 修订；不能将早期未含捕食、狩猎的范围当作当前限制。

### ADR-0016

**发展预算与按变化刷新。保留；2026-10-03。** 用户要求百年实际进展、不同发展偏好、紧凑详情与软键盘可用。共享下一项目物资预算避免住房／拓荒耗尽研究材料，呈现按逻辑和视野失效，输入适配补当前框架缺口。

不承诺每个灾难世界晋升；缓存复杂度及输入重复路径需回归，升级框架时评估移除适配。延续 [0013](#adr-0013)，按需规划后来由 [0029](#adr-0029) 细化。

### ADR-0017

**可辨识地图与多物种。部分保留；2026-10-03。** 用户要求紧凑控制、损伤说明、种族／职业差异、山河连接和多物种，替代 [0015](#adr-0015) 单物种表示。透明小位图、分块纹理和实际底部遮挡降低重复绘图成本。

共存增加计算和保存成本，视觉高度不引入楼层或碰撞。分区提交由 [0018](#adr-0018) 调整，物种与捕食由 [0022](#adr-0022) 扩展；旧物种数量不再维护。

### ADR-0018

**分区生态与可响应保存。部分保留；2026-10-03。** 用户允许优化五倍速度的算法和数值。区域共同初态、按日序提交、增量计数与分段捕获控制重复计算，扩展 [0017](#adr-0017)、[0007](#adr-0007) 和 [0008](#adr-0008)。

稀疏提交改变轨迹，保存捕获短暂停表，软预算不能中断原子步。早期固定六日周期由 [0022](#adr-0022) 每日预算替代；整体字符串开销由 [0032](#adr-0032) 改为分块路径，最新调度见架构。

### ADR-0019

**到场占地、供水与升级。部分保留；2026-10-03。** 用户要求人口只提高范围、到场简单登记、独立供水、建筑升级和轴向桥梁。复用目标与劳动体系，生成时计算淡水距离，避免持续全图成本。

保存和初次撤销仍有成本。原河湖有限额度已按用户后续要求改为无限，见 [0020](#adr-0020)／[0022](#adr-0022)；城镇扩充见 [0021](#adr-0021)，水井现行取舍见 [0030](#adr-0030)。

### ADR-0020

**可达补给与渐进灾害。保留并修订；2026-10-03。** 用户反馈有粮却饿死、取水不足及灾害瞬间扩散。检查出生连通性、真实可达资源和当日补给顺序，火灾及疫病按快照渐进传播，实物扑救共享日额度。

仍是有界模型，不含风向或精细病原。2026-10-04 用户明确河湖无限，替代 [0019](#adr-0019) 及本项早期限额；陆地有限额度和实际运输保留，生成地理由 [0022](#adr-0022) 继续修订。

### ADR-0021

**付费扩充、地理设施与有界导航。部分保留；2026-10-04。** 用户要求扩充付费与独占土地、船坞码头分离、按用途选址，确认人口门槛和等级保留。沿用 [0019](#adr-0019) 登记及 [0014](#adr-0014) 载具，限制无目的建桥与循环寻路。

局部搜索不保证全局最优。固定升级面积由 [0024](#adr-0024) 动态面积替代，未登记地建造和反复开启标记由 [0023](#adr-0023) 替代，默认部落由 [0022](#adr-0022) 修订。

### ADR-0022

**生成地理、种族栖息地与食物链。保留并修订；2026-10-04。** 用户要求独立地理、出海河流、宜居部落和种族设施，随后允许大幅改变生态以控制成本、植物按年复评。洪泛排水树、通行与宜居分离、连续群落和每日预算替代 [0018](#adr-0018) 的固定周期，修订 [0019](#adr-0019)／[0021](#adr-0021) 的生成规则。

稀疏更新近似自然过程并改变轨迹，原生耗时不能换算浏览器帧率。捕食／繁殖有效间隔由 [0024](#adr-0024) 修复，食物网容量与压力由 [0029](#adr-0029) 替代早期参数。

### ADR-0023

**连通城镇、稳定任务与真实捕鱼。保留；2026-10-04。** 用户要求设施附着连续登记地、任务稳定和舟船捕鱼。替代 [0019](#adr-0019)／[0021](#adr-0021)／[0022](#adr-0022) 中的未登记建造及标记选择；中心连通根和水格附属语义可解释孤地释放。

断地后建筑暂停，持续任务可能次优，生存和危险仍可打断；渔船沿用个人载具而非船队。通行、归属修订缓存减少无变化遍历，导入仍独立检查。

### ADR-0024

**城镇生效与可执行任务。保留并修订；2026-10-04。** 用户要求占地约束加成、降低领地外采集、说明建造和劳作依据。动态菱形面积替代 [0021](#adr-0021) 固定面积，到场可达的来源、施工和说明共享规则，避免显示工作却未到场。

长期对照发现 [0022](#adr-0022) 捕食与繁殖有效间隔不一致并修复；现行平衡后来由 [0029](#adr-0029) 修订。局部路径与实际生态仍受地形及破坏影响，对照不保证任意世界稳定。

### ADR-0025

**早期帝国研究与分组卡片。部分被替代；2026-10-04。** 用户要求扩展科技树、完整模拟并交付存档。统一规则图、真实材料预算、采矿目标及投产记录帮助定位实际发展阻塞。

分组卡片由 [0026](#adr-0026) 节点图替代；人造帝国知识与奖励由 [0028](#adr-0028) 文明结果替代。预算、住房、水上施工和途中恢复理由保留；繁荣规则实验不证明任意战争／灾害世界必达终点。

### ADR-0026

**真实依赖节点图。节点图保留，布局被修订；2026-10-04。** 用户强调科技“树”，用连接展示分叉、汇合，替代 [0025](#adr-0025) 换行卡片；只读布局不新增研究依赖。

全树混排及外围长线难读，由 [0027](#adr-0027) 分线布局替代。连接覆盖、节点／线路安全与真实触摸验证保留，小屏可读性仍须查看实际画面。

### ADR-0027

**独立路线与支线排位。布局保留，帝国汇合被替代；2026-10-04。** 用户反馈连接图难读，替代 [0026](#adr-0026) 混排、外围连线和默认全祖先强调；树保留拖动、缩放与全部真实前置。

固定支线增加维护成本，节点拖动还需处理指针捕获和嵌套滚动。帝国汇合节点与虚线由 [0028](#adr-0028) 删除，结构测试不替代桌面／触屏可读性。

### ADR-0028

**文明结果与研究玩法。保留并修订；2026-10-04。** 用户明确帝国不是科技名称，要求研究解锁真实建筑、岗位、战斗与操作。替代 [0025](#adr-0025) 帝国知识／奖励及 [0027](#adr-0027) 汇合节点，达标从真实知识、运作设施与首批生产派生。

服务和装备增加保存及校验成本，折跃尚无自主寻路。每线固定设施认证由 [0029](#adr-0029) 按需条件替代；无现行用途的研究空编号由 [0033](#adr-0033) 取消，不能沿用旧要求。

### ADR-0029

**平衡食物网与按需发展。保留；2026-10-05。** 用户要求连续捕食压力、猎物不足先伤捕食者、真实养殖及合理建设。共享食物预算推导补充通量，替代 [0022](#adr-0022)／[0024](#adr-0024) 部分参数；必要产业与用途判断替代 [0028](#adr-0028) 固定闲置设施认证。

满容量平衡限固定适宜环境。完整研究实验显式提供付费议程，纯自治可略过无用途军备；稀疏生态仍近似连续群落。居民保护性采集由 [0030](#adr-0030) 补充，不给自然捕食加保底。

### ADR-0030

**低密度采集与紧凑概览。保留；2026-10-05。** 用户要求居民减慢稀疏来源采集、选择更好地块、缓慢扩散、具体植物和单一供水字段。沿用 [0029](#adr-0029) 自然捕食，保护性决策属于居民；数量为实际连续生物量，恢复容量统一。

水井后续采用天然供水阈值和线性增量，修订 [0019](#adr-0019)／[0021](#adr-0021) 的井能力说明。仍须现场取水和共享日额度；摘要减少信息，完整资源保留在详情。

### ADR-0031

**聚落分区、完整返回与临时暂停。保留；2026-10-05。** 用户要求检查界面入口合理性。固定聚落页签、有界导航快照及原世界／窗口／会话绑定补齐 [0005](#adr-0005) 编辑边界，避免取消窗口改变运行偏好或旧任务操作新世界。

增加 UI 会话状态与失效验证成本，但不保存跨会话浏览历史或多级撤销；取点复用原上下文并保留触屏返回。

### ADR-0032

**精确紧凑存档与分块压缩。保留；2026-10-05。** 用户要求缩小冗余和自动保存卡顿。扩展 [0008](#adr-0008)／[0018](#adr-0018)：定义安全零值，精确稀疏物种编码，直接文本块捕获与后台平台写入，不删除因果状态。
