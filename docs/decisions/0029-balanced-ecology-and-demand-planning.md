# ADR-0029：平衡食物网与按需发展

状态：采用，2026-10-05。来源：用户要求生态容量平衡、猎物不足主要导致捕食者死亡、捕食压力连续增加，并要求真实养殖、合理建设／研究、减少往返及界面噪声。

## 决定

食草物种共享植物供给；捕食者共享兼容猎物生物量。用满容量食物网推导食草补充通量，保证固定环境的满容量平衡。需求不足时先按连续饥饿比例削减捕食者，严重过量仍可连续增加到完全消耗猎物；没有强制保护数量或灭绝开关。迁移按密度差消耗幸存者。每日仍最多复评 256 格，无帧率或随机源变化。

牧场与水产养殖厂从实际野生种群取种，喂养、繁殖、收获和返仓均需真实现场劳动与物资。降低野生容量同时让养殖成为可经营的生产方式。新状态使用格式 15，严格校验并拒绝旧格式。

发展检查本地需要及当地已知事实。基本缺口在进行其他项目时也可建设；有用且已解锁的设施优先、可选缺料项目跳过、工位饱和及用途才触发升级。军事、铁路、空间、医疗等研究有用途门槛。完整研究路线的专门实验明确提供付费议程，不把和平自主跳过军备误判为停止研究。

帝国仍需完整路线知识与实际投产的必要产业链。医疗、军事和传送设施按需建设，不要求每个和平城镇为认证而空建；此条替代 ADR-0028 的每线十四种固定设施要求。图形科技树、独立动力及没有帝国奖励的决定保留。

## 代价与验证

容量是归一化连续种群模型，并非逐只动物，稀疏复评仍近似自然过程。满容量平衡针对固定适宜环境；破坏、捕猎和缺水可以改变结果。回归覆盖六种栖息地满容量平衡、捕食压力连续性、饥饿大量死亡、严重过量耗尽、四个自然世界长程多样性、实物养殖与中途恢复。行为及界面证据见验证记录。

旧决定保留：此决定替代 ADR-0022、ADR-0024 的部分容量／捕食参数，替代 ADR-0028 的固定设施认证条件。

居民低密度采集、迁移速度与简要概览的后续修订见 [ADR-0030](0030-sustainable-collection-and-compact-selection.md)；自然捕食连续性的决定保留。
