# ADR-0012：有限战争、实际战报与只读故事观察

- 状态：采用，补充 [0011](0011-evolution-and-map-tools.md)。
- 日期：2026-10-02。
- 来源：用户选择补齐第三轮剩余功能，并经同步问答选择“有限占领与防御”；阈值、采样窗口和记录容量是本批工程选择。

## 决定

进攻军令对应一个已获知的聚落，防御军令保护家园。达到目标或需要撤退时停止本次作战，现场见证者形成战报，经实际递送后机构再决定停战与恢复。部队拥有现场状态，国家军事记录只包含命令和已收报告。军令征募去重，避免返乡后被旧命令立即再次征募。

人物故事与事件因果来自结构化、可核对的项目、消息和经历。事件聚合只改变呈现；原始事件及 ID 保持独立。人物记忆与真实后果分别展示，不根据相似文字或时间接近编造前因。

关注属于当前世界会话的观察状态，不进入模拟存档。项目进度样本属于随项目恢复的记录，但预估查询只读；只在足够且稳定的实际工作样本下给出模拟日预估。

新增军事、消息及项目数据统一进入格式 5（合并时远端格式 4 已用于外交态度和军令顺序，本次避免复用同一版本表示不同状态），按 alpha 约定拒绝旧格式，不提供迁移。历史引用可以超过日志保留范围，但不能指向未来事件或形成循环。

## 原因与代价

单一有限目标让占领、失败与撤退可以解释，并为恢复期提供具体依据；实际战报保持距离与通信设施的意义。每国仍只有一支军队与最近一次机构军事记录，复杂多战线指挥需另行设计。

聚合和人物故事复用已有有界记录，控制保存与界面成本；因此不会保存无限人生史，也不能保证为每个事件找到仍保留的前因。项目贡献者、速率样本和时间窗口的上限见产品文档，调整时同步核对存档校验及浏览器规模表现。

## 验证与重新评估

`StoryTests.cs` 验证战报延迟、军令去重、目标失效、家园防御、项目贡献、预估失效、聚合只读和非法存档。`tests/browser/stories.cjs` 用普通导入与真实输入检查桌面／触屏呈现和保存恢复；使用只读 UI 快照，不提供模拟修改后门。

长期平衡、更多浏览器和真实设备的结论须以 [验证记录](../verification.md) 为准。需要多战线、家族继承、跨会话关注或无限历史时重新评估相应状态归属与容量。
