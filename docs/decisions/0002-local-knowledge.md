# ADR-0002：角色基于自己的知识行动，信息与物资实际传递

- 状态：采用
- 记录日期：2026-10-01
- 来源：用户明确要求减少纯随机，以需求、性格、职业、环境和资源驱动行为，并限制异地通信；结构化事实、目标评分、投递队列及其衰减规则属于工程选择。

## 背景

每步随机游走或直接读取全球状态，会产生难以解释的行为，也会使道路、信使、地区差异失去作用。世界事实、角色观察和角色后来听说的事情需要区分。

## 决定与约束

- 角色根据自身需求、性格、职业、可观察环境和已知信息选择目标；界面理由应对应真实决策依据。
- 消息记录观察时间、获知时间、原始来源、原始职业、转述者和可信度；旧消息可以影响选择，但不能伪装成最新世界事实。
- 当面交流经待投递队列到达，不能在同一步无限接力；信使、商旅需要实际移动，货物放在随身库存中。
- 劳动、进食、交付、研究及设施运作受位置与资源约束，不能用全局定时器替代实际过程。
- 远程通信需要运作中的设施、覆盖和连接；仅解锁科技不带来全球通信，抵达时也需处理失联。
- 本轮不加入随机谣言；自由文字只作记录和解释，不调用在线语言模型执行指令。

## 原因与代价

信息延迟和实体运输把角色选择、地理条件与社会决策连接起来。玩家可以追查“知道什么、何时知道、因此做了什么”。

代价是角色会因旧知识作出不再适合现状的选择，运输可能受阻，状态和存档也更复杂。这些现象需要可观察的原因，不能用无解释的随机变化掩盖实现问题。

全局广播、隔空结算和随机目标是更简单的备选，但不符合已确认的行为与通信约束。当前仍允许有种子的随机性表达自然变化；“减少纯随机”不是禁止所有随机数。

## 重新评估条件

新增通信方式、误导信息、复杂导航或更大规模物流时，先定义观察、发送、接收、失效与成本语义，并补充相应因果验证。
