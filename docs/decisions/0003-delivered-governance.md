# ADR-0003：制度根据已递送的公民意见作出决策

- 状态：采用
- 记录日期：2026-10-01
- 来源：用户明确要求公民按制度、身份和议题相关性影响集体决策，意见需要传播；聚落报告、去重方式及具体权重属于当前工程选择。

## 背景

如果国家直接扫描每个居民的思想，个体知识与实体通信的约束就会在政治层失效。如果所有声音同权或转述一次算一票，制度差异与来源可信度也难以产生合理影响。

## 决定与约束

- 当前自治政策以接收聚落实际获得的报告为输入，不读取全国角色尚未传达的内心状态。
- 报告保留原始公民、原始职业、议题、观察时间、接收时间、可信度及事实编号；信使身份不能覆盖原作者身份。
- 同一事实重复递送不能重复计票；同一来源的同类议题使用最新报告，避免转述放大政治影响。
- 制度权限、职业与议题相关性、紧迫程度、可信度和消息年龄共同影响政策评分。
- 决策说明引用实际获胜议题的证据。形成的政策和研究信息仍需通过既定传播渠道影响其他地方。
- 玩家指定政策属于显式覆盖，自治不能悄悄改掉；恢复自治后再由报告驱动决策。

## 原因与代价

这一方式让公民活动、运输与政治形成可追查的因果链，也允许同一批证据在不同制度下得到不同结果。

代价是制度和权重仍是简化模型，需要通过场景和后续平衡调整。当前政策计算不等于完整选举、阶级、合法性或自主外交系统。

全体公民即时投票、纯随机国策和读取全国资源直接选最优政策都更容易实现，但会绕开用户确认的传播与身份差异。具体数值不是永久产品承诺，可以在保留上述约束的前提下调整。

## 重新评估条件

新增制度、代表选拔、合法性或跨地区政治时，重新定义谁有发言资格、意见如何到达、如何去重以及权重依据，并验证相同证据下的制度差异。
