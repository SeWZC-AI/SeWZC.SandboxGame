# ADR-0005：角色编辑改变未来，不重算世界过去

- 状态：采用
- 记录日期：2026-10-01
- 来源：用户明确要求编辑角色属性、思想、记忆与历史，修改影响认知和后续行为而不回算过去；候选副本验证、事实修订编号和结构化编辑器属于工程选择。

## 背景

玩家需要直接干预角色，但历史事件已影响资源、死亡、战争和其他角色。把修改个人记录解释成重演过去，会造成难以预测的连锁变化，也无法仅靠修改一份档案保持一致。

## 决定与约束

- 角色编辑先构造候选副本，校验数值、位置和实体关系后再写入；无效输入不能留下部分修改。
- 修改属性、目标、性格和记忆影响后续模拟。结构化经历的变化可以影响人格，已发生的世界事件和资源结果不因此重新计算。
- 改写记忆内容形成新的事实修订编号，已经传播的旧副本保留原来的信息；新增记忆由核心分配编号并补全来源。
- 玩家设置运输或递送目标时，需要初始化实际任务，而不是只改档案里显示的文字。
- 自由文字只作为记录或理由，不作为脚本执行；结构化表单是主要入口，原始 JSON 是高级入口。
- 查看角色、定位和筛选日志不修改世界。编辑撤销另以完整世界快照恢复本轮编辑前状态，不能只回滚局部显示。

## 原因与代价

这一语义使沙盒干预可预测，并保留已经发生的因果结果。副本验证避免玩家遇到“提示失败但世界已改了一半”的状态。

代价是被编辑的个人经历可以与客观世界记录不同，需要明确显示编辑性质。玩家也不能通过改写一段文字自动复活角色或撤销战争结果。

回溯重演和分支时间线是可能的独立玩法，但当前没有实现其完整状态与因果处理。仅修改描述、不影响后续行为的备选则不能满足用户希望编辑思想与历史的目的。

## 重新评估条件

如果时间旅行、历史重演或分支世界成为明确需求，应单独设计世界级操作；扩展档案字段时继续验证原子写入、未来行为和既有世界结果三条边界。
