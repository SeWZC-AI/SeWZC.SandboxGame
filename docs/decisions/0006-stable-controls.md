# ADR-0006：核心操作位置稳定

- 状态：被 [ADR-0011](0011-evolution-and-map-tools.md) 替代；稳定入口与编辑可达性的原则保留。
- 记录日期：2026-10-01
- 来源：用户明确要求避免按钮数量变化导致位置跳动；固定槽位和分页属于当前工程选择。

## 背景

工具类别、所选对象和可用动作会频繁变化。随动作数量重新布局会移动常用入口，导致误触，也使手机操作难以形成稳定习惯。

## 决定与约束

分类、工具与时间控制各自保留稳定区域，内容变化在区域内部处理；不可用项使用明确禁用状态。当前采用六类、八个工具槽及分页、固定宽度的时间按钮；槽数是可调整实现，稳定性才是产品要求。

编辑表单的提交、取消保持可达，长内容在内部滚动；定时刷新与屏幕旋转不能丢失正在输入的内容。响应式布局允许因窗口尺寸变化而重排，不允许因状态刷新持续跳动。

## 原因与代价

动态紧凑排列可以省空间，但在频繁切换中会破坏位置记忆。固定区域保留少量空位，也增加分页与窄屏设计成本；当前以减少误触和保证可达性为优先。

## 重新评估条件

新动作超出容量或真机操作暴露空间问题时可改变槽数与布局，同时更新几何和触屏验收。无需把八个槽永久固化。
