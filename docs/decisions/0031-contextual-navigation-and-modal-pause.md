# ADR-0031：聚落分区、完整返回与窗口临时暂停

状态：采用，2026-10-05。来源：用户要求分析每个界面入口的合理性，并继续优化；下述页签划分和状态边界是本次工程选择。

## 背景

研究嵌在建设长页中，通信入口在底部，聚落缺少独立列表。返回只保存实体 ID，遗漏地图选择类型、跟随和研究视野；关闭后仍复用旧路径，历史超过 32 层则全部清空。部分窗口打开就改变玩家暂停状态，取消仍停表；建造、施法与铁路坐标没有地图取点，研究施法默认可能来自另一聚落。

## 决定

聚落有独立列表，概况、建设、研究、通信使用固定页签与同一聚落选择，概览另提供研究和通信捷径。相关对象通过详情链接互相访问。研究保留独立全屏视野，建造工具继续直接作用于地图。

导航快照包含对象与地图选择、跟随、折叠项、展开、滚动及研究视野，仅保留最近 32 项。关闭、地图重新选择或工具操作结束浏览会话；延迟恢复检查导航世代。普通查看不修改模拟或存档。

窗口与地图选点属于临时停表，取消不改变玩家运行状态；编辑提交仍创建恢复点并暂停。异步提交绑定世界、窗口和导航会话，恢复点读取可取消，重复提交不执行；等待期间锁定原表单输入并保留取消。旧请求不得修改新世界或关闭新窗口，旧地图笔触也在换工具、打开窗口或进入取点后失效。捕获恢复点期间临时停表，只有有效命令提交才改变运行偏好；命令部分成功后报错仍保留恢复点供撤销。

地图取点验证窗口与世界实例，提供触屏返回并恢复原地图选择与跟随；取点期间保留平移、缩放和返回操作，工具和其他页面入口不改变原上下文。异步导出保存原世界与窗口世代，防止旧任务关闭后开的窗口或导出替换后的世界。研究施法只列当地存活成年人，居民入口优先本人；默认目标随施法者变化，玩家选定的目标保留，即使选点坐标与默认值相同。对象链接名称与目标同步刷新，对象缺失时禁用。法术效果和实际成本仍由核心命令校验。

## 原因与代价

固定聚落页签让同一对象的建设、知识与通信更容易找到，同时减少单页长度。导航和取点快照增加了呈现状态，但避免把界面访问变成世界修改；它们不提供跨会话历史或多级编辑撤销。不同页面的内容重建仍受现有选择键控制，周期刷新保持输入控件。

## 验证

Headless 回归覆盖返回选择、跟随与研究视野、有界历史、窗口取消／提交、聚落入口、地图选点与施法上下文，以及异步导出、取消提交和旧窗口失效。浏览器 `entries.cjs` 使用真实桌面／触屏输入检查入口可达、固定页签、取点返回、受限入口和只读存档不变。实际结果与环境记录在 [验证记录](../verification.md)。
