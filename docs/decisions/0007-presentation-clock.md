# ADR-0007：离散模拟与连续呈现分开

- 状态：采用
- 记录日期：2026-10-01
- 来源：用户要求角色每帧平滑移动；独立呈现时钟与插值属于工程选择。

## 背景

模拟按离散步骤更新地格位置，直接绘制会表现为跳动。把渲染帧率当模拟频率会让设备性能影响规则，查看和镜头操作也可能意外改变世界。

## 决定与约束

Core 保存逻辑位置及移动过程；呈现层以独立时间在真实位置间插值，不推进模拟、不消耗世界随机数。暂停冻结已显示位置，变速调整呈现节奏，载入与同 tick 的编辑传送重置轨迹。

地图命中和跟随需要对应实际显示中的居民。选择、筛选、缩放、平移和跟随只改变呈现状态；生产、运输和消息到达仍由逻辑规则判断，不能用动画掩盖隔空交付。

## 原因与代价

持续高频更新整个模拟或采用连续物理会增加浏览器成本，并扩大规则改动。插值适合当前地格世界，但显示位置可能略滞后于逻辑位置，需要明确处理暂停、载入、变速和传送边界。

## 重新评估条件

引入连续物理、后台模拟线程或新渲染后端时可调整表示；观察行为不影响世界结果的约束仍需保留。

## 实现与验证

- [运动轨迹](../../src/SeWZC.WorldBox.UI/Controls/EntityMotionTrack.cs)、[地图运动呈现](../../src/SeWZC.WorldBox.UI/Controls/WorldMapControl.Motion.cs)。
- [运动检查](../../tests/browser/motion.cjs) 读取最后实际绘制位置，验证同一模拟 tick 内的连续位移、暂停、变速、点选和跟随；比较完整存档及随机状态，不能只断言插值公式的预期值。

### 2026-10-02：动作特效与路线预览

按新增需求，火灾、陨石、战斗和施法也使用呈现时钟。核心只发布有界的已执行动作通知，动画不延迟或重复执行实际效果；暂停冻结，载入清空短暂通知，持续火灾重建自地格。通知不作为存档事实，不消耗随机数或世界 ID。

路线预览复用真实局部导航，最多展示当前目标下 24 格，不预测新目标或突发事件。`effects.cjs` 读取实际绘制帧的特效数据并保留截图，检验无居民场景的独立动画和暂停；核心用完整存档比较验证预览只读，并逐步比对真实移动。
