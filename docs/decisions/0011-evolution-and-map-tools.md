# ADR-0011：自主文明与可收起的地图工具

- 状态：采用，替代 [ADR-0006](0006-stable-controls.md) 的常驻工具布局。
- 记录日期：2026-10-01
- 来源：用户反馈玩法停滞、工具混乱、手机空间不足，并在确认方案后要求修改部署。

## 决定与约束

地图工具只执行地图动作。观察、导航和世界规则有独立入口；分类切换不激活工具或弹窗。工具与详情默认收起，手机上互斥，保留固定的时间控件和可见的返回、关闭。按钮图标使用矢量路径。

数字使用有范围的数值输入，枚举与实体使用有名称的选择器；仅名称、可选备注及叙述允许文字。备注明确不执行指令。放置预览与提交共享只读校验，失败说明就近展示，触屏单次工具先预览再确认。建筑默认赐予，可选择实际消耗材料和等待施工；运作仍需人员及研究。

文明发展展示当前计划、实际进度与阻碍，自主外交依据送达的信息，迁徙需实地抵达，分裂依据机构收到的持续困苦报告。接触、提议与冷却进入当前格式 3 存档。时间节奏是体验目标，不通过定时凭空制造事件实现。

## 原因与代价

常驻工具和大量观察入口压缩地图，又不能解释发展为何停止。可收起布局优先保证地图空间；展开时保留动作槽位与分类区域，隐藏无用项。发展与外交增加实际可观察变化，同时需要保存更多因果状态、验证消息边界和调节长期平衡。

本轮只提供有边界的古代模拟。四类研究、局部寻路和简化战争仍然限制长期多样性；事件数量不能直接证明好玩。真实手机体验和更长周期平衡需要后续测量。

## 实现与验证

- `WorldEngine.Evolution.cs`：世界规则、发展摘要、外交、迁徙及分裂。
- `MainView.Inputs.cs`、`MainView.Rules.cs`、`WorldMapControl.Tools.cs`：结构化输入、规则、预览。
- `EvolutionTests.cs` 及真实浏览器桌面／触屏／运动检查验证状态边界与操作；具体结果见 [验证记录](../verification.md)。
